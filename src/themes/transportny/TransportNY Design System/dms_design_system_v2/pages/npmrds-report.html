Design rules this set forced
  • 01Two affordances per row, never more. Rename and remove sit in the row; everything else waits inside the open-out. At 340 px a row with six icons is unreadable and the route's name — the thing you scan for — loses its width.
  • 02Editing is explicit, saving is not automatic. Name and dates both take a save/cancel pair. Colour and graph chips commit on click — they're single, reversible, cheap.
  • 03Presets before fields. AM Peak / Weekdays are the real vocabulary; the raw time inputs stay, but nobody should have to type 16:00 twice from memory.
  • 04Destructive is the only coloured control. Amber = you are editing; rose = removal; blue = the one primary action. Nothing else earns a colour.

// the density rule
Twenty-one sections is a real page.

“Year Over Year (Beginner)” carries two maps, thirteen bar graphs and four tables. The design has to survive that, not just the five-section case.

  • 01Break on question, not on count. One band per question, with a fused lexical head naming it. Four bands maximum before the page earns an in-page nav rail.
  • 02Same question, different resolution → fuse. Zero the shared edge's padding and coordinate the corners; two sections read as one card.
  • 03Never below size 4. At size 4 the y-axis drops to three ticks and the legend collapses to dots plus a count. Below that a chart is decoration.
  • 04One attribution line, always. Truncate rather than wrap — three wrapped lines of provenance on a size-4 card outweigh the chart.

// what changes on paper
Chrome is not content.
  • 01Drop every affordance. SideNav, the ds-nav widget, quick-control pills, kebabs, Edit, Share — none of it survives a PDF, so none of it prints.
  • 02Promote the finding. On screen it is a canvas section under the header (it left the rail when the rail became a control surface); on paper it leads, because a printed report is read linearly and often only page one.
  • 03The rail becomes a legend. Route colours still key the charts, so the rows persist as a static colour key — without the mutation controls.
  • 04Provenance and pagination move to a page foot. The per-card attribution lines collapse into one sheet-level line — the same facts, once.

Scope note: this is one drawn state, per Open question 4's recorded default. A real print stylesheet — page breaks that never split a card, repeated headers, widow control — is its own task.

// 04 design states · not a band on the live page

The search dialog, in four states.

The query lives in the URL — ?search=bridge&region=8 — so a result set still travels in an email. Only the open flag is in-memory, which is what state 1 is about.

documented as patterns.html §11 · modal variant
state 1 · arrived on a shared link · dialog closed, query live
clear

Action params never reach the URL, so the dialog cannot auto-open from a link — but the Filter's own params do, so the trigger reports the query and every facet riding with it, and one click reopens the results. This is the whole cost of the modal treatment, drawn rather than described.

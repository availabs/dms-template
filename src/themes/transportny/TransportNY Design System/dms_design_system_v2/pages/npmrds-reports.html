// 04 live component · not a band on the built page

The search dialog, working.

The query lives in the URL — ?search=bridge — so a result set still travels in an email. Only the open flag is in-memory, which is what the fourth button below is about.

documented as patterns.html §11 · modal variant
reach a state
what is wired

The query (an OR group of like leaves over name + description) and three facets that are genuinely expressible as filter leaves: recent (the shipped op:'time' “last N” preset), rebuilt (a plain filter leaf) and described (the notempty unary — the gap-filter idiom).

what is drawn but inert

mine — not expressible today; nothing injects the current user into a filter value (Escalations). region · measure · year · folder — the legacy table has no such columns, so they need the metadata the build task denormalizes. Both carry a title saying so.

what a build must know

Action params never reach the URL, so a shared link arrives with the query live and the dialog shut — the closed trigger must report it. And a modal only behaves as a modal on a published page; in edit mode the group renders inline, which is how authors reach it.

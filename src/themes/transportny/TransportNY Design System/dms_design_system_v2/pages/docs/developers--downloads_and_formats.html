The Macro View package

The builder on the Macro View exports exactly what the map is drawing: one row per segment for the PM3 year, with the measure the map shows, the identity columns, and any columns you add. Two formats, csv and gpkg; geometry is optional in the CSV and required for the GeoPackage to be a map layer. JSON was removed on 2026-08-24 because the export pipeline cannot write it, and GeoJSON is refused as a matter of policy. A Shapefile is accepted by the server but not offered in the builder. The steps are on Download data from the Macro View.

Column names follow the dataset's scheme: measure, variant, period and unit joined by underscores, as in lottr_amp_lottr and ted_freeflow_anchored_all_xdelay_vhrs. The identity columns include the TMC code, the year, the county, the region, the MPO and the urban area. The dataset carries no road name; join the TMC code to the TMC network for names, lengths and AADT.

PM3_README.txt is written for the year exported, so two years' packages read differently. Its sections: the export (source, year, format, scope, row filter, column list); the coverage era of the year for the all-vehicle and truck streams, with a warning when the year crosses an era boundary; the fixed free-flow reference window, whether the year overlaps it, and the anchor_fallback rows to exclude from a trend; the delay columns, which variant answers which question, the 20 mph floor and the share of delay it governs, and an AADT-vintage warning when the year sits on a revision boundary; the reliability columns and their precision fields; and a checklist for comparing years that ends "not for federal submittal". The warnings are computed from the year, not pasted in.

The MAP-21 annual file

The file under Annual data · HPMS Travel Time Metrics on the MAP-21 pages is the submission NYSDOT files with FHWA each June 15: one row per reporting segment, both directions, with the per-period LOTTR and TTTR ratios and percentile travel times, PHED hours, and the segment's system, length and directional AADT. The Year selector switches the file. The button reads Download CSV; at the 2026-09-08 check its address was a placeholder that did not resolve, so the file is not yet served. This file, not a Macro View download, reproduces a federal figure. See The annual download and the PM3 and MAP-21 datasets datasheet for its columns.

The TSMO Data & Methodology downloads

The page's Downloads & API band has two cards. open data source → leads to the excessive-delay series source page, whose Download hands you one zip holding a CSV per year: 4,927,052 rows over 9 year files, about 143 MB, generated on 2026-07-27 without the geometry column. The API card leads to the API guide. The band's copy names "CSV / Parquet"; the generated file is CSV. Both cards replaced links that did not work, reported in July 2026 and fixed on 2026-07-27. The Excessive-delay series datasheet says which years the file holds; the dashboards themselves have no download control.

Source-page exports and how they are generated

Every dataset in Data & Downloads has a source page, and every version of it can carry generated files. A download exists only where a file was generated for that version. Administrators generate them: a request names the view, the columns and the formats, and a server job writes each format with the GDAL ogr2ogr tool and records the file addresses on the view. The four formats the job can write are CSV, ESRI Shapefile, GeoJSON and GPKG, GPKG being the GeoPackage. On 2026-07-27 the 23 Freight Atlas versions without a file were generated as CSV, Shapefile and GPKG, so every Freight Atlas version now has a download; the 28 that already had files carry GeoJSON as well. The catalog's design listed XLSX; no code writes it.

The files sit in object storage at https://availabs-bucket.files.availabs.org/… and the addresses are plain: a file that has been generated can be fetched without a token, and each of the 23 was verified fetchable. The source page that lists them is another matter: at the 2026-07-29 check the catalog showed the sign-in page to visitors without an account. What needs a login carries the record. Through the API, a view's metadata attribute holds the same addresses under download, keyed by format. Uploaded documents, such as the plan library's PDFs, follow the same rule: the file address is public even where the page is not.

Report Data links

A report's header shows a Data button only when its author set a Data link; it opens that address in a new tab. What it points to is the author's choice, so its format is whatever they linked. A report's own address reproduces the view but does not freeze the numbers; for a figure you must defend, take the file behind Data or export the measure from the Macro View. See Share, print and publish a report.

What is not downloadable

  • The raw 5-minute travel-time table. No page offers a file. The Macro View package carries computed measures per segment and year, not epochs. The NPMRDS travel times datasheet says what the table holds.
  • The routes table. No page offers a download of saved routes. A route's address loads it for anyone; see Routes data.
  • The Route Comparison matrix. The draft tool does not yet offer a download of its own. Copy the cells, or build the question as a report.
  • The TSMO dashboards. No dashboard has a download control. The data behind them is the per-year CSV above.
  • Any format a job did not write. A source page offers only the formats generated for that version; the Macro View offers CSV and GPKG only.

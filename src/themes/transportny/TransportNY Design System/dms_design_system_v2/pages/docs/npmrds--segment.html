Look at one segment (TMC).

A segment page shows everything the platform knows about one Traffic Message Channel (TMC) segment: its attributes, how much of its data arrived, its speeds by peak period and its PM3 measures year by year. The page is a design and is not live. This page says what it will show and how to reach a single segment today.

Before you start

A TMC segment is one directional piece of road, a few hundred metres to a few miles long, identified by a 9-character code such as 120N04521. The TMC network and its vintages explains the unit. The segment page is designed but not built, so there is no link to it from the Macro View hover or from a report. Today a single segment is reached through the Macro View, through a one-segment route in Reports, or by filtering a Macro View download. The steps below use those three paths; the section after them describes the designed page.

Steps

  1. Open Macro View and set the measure and year you care about.
  2. In the measure panel under Get to a segment, type at least three characters of the TMC code, or a county name, into TMC or county… and select the result.The map zooms to the segment. The search does not know road names.
  3. Hover the segment.The popup shows the TMC code, the measure's value for the selected period, the county and the region. The road name is not shown.
  4. Change the measure or its Peak period and hover again to read another value for the same segment. Each read is one year's annual value.
  5. For the segment's history over time, open Reports, select New route, add the segment by its code in TMC search, and save it as a one-segment route. Create a route walks through it.The route can be put in any report or template. Snapshot gives an average day; Year Over Year gives the trend.
  6. For the segment's row in the data, add its county under Geography on the Macro View, open Download N rows, add the columns you need, build the CSV, and filter it by the tmc column in your spreadsheet. Download data from the Macro View has the builder.

What the designed page shows

The design is a leaf page for one segment, headed by its code, with four blocks and four page controls. Nothing below is on a live page yet.

Attributes
31 fields from the year's network table: geography, geometry and length, AADT for all vehicles, passenger vehicles, single-unit and combination trucks, route signing, functional class, facility type, lanes, direction, NHS and STRAHNET status. TMC network has the fields.
Completeness
The share of the year's 5-minute epochs that reported, out of 105,120 possible, with the worst month, the best window and a month-by-hour grid. The design's example reads 80.7 %. Data coverage defines the measure.
Speed by peak
The speed distribution for each period: overnight 20:00 to 06:00, AM 06:00 to 10:00, off-peak 10:00 to 16:00, PM 16:00 to 20:00, weekend 06:00 to 20:00, with an outlier control (Keep all · Within 3σ · Within 2σ). Peak periods and epochs has the windows.
PM3 history
LOTTR, TTTR and PHED for the segment, each year from 2016 to the latest, as lines. PHED is labelled as an urbanized-area measure. See LOTTR, TTTR and PHED.

The designed controls are Year, Metric (Speed · Travel time), Data source (All vehicles) and Resolution (Hour · 15 min · 5 min), with Share, Download, Add to a route and a CSV per card. The earlier NPMRDS tool had a segment page of this shape; the design transcribes it onto the current data.

Limits and gotchas

  • There is no segment page, no link from the hover, and no Add to a route button today. The hover's TMC code is the handle; copy it.
  • Codes change between yearly maps. A code from the 2026 map may not exist in an earlier year's data, and a segment can be split or merged. One map per year and two segment counts explains.
  • The Macro View's dataset carries no road name, length or AADT, so the hover cannot name the road. The TMC network datasheet does.
  • Very short segments are flagged unreliable far more often than long ones. Read a single segment's ratio next to its length.
  • A one-segment route is hidden behind Show short segments too in the route pickers; see Find, edit, tag and share routes.

Troubleshooting

"no segment matches"

The Macro View search matched nothing. Check the code has 9 characters and that the year's dataset holds it; try the county name instead and find the segment on the map.

"TMC not found" in Route Creation

The code is not on the 2026 network the route tool draws. Look it up on an earlier year in the Macro View, or click the segment on the route map instead of typing it.

The hover shows a value I did not expect

The hover reads the selected measure, period and year. Check the Peak period control and the Year before comparing it with another source.

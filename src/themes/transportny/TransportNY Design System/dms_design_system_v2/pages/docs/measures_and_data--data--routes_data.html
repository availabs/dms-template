Routes data.

The table of saved routes: one row per route, each a named, ordered list of TMC segments made in the Route Creation tool and read by Reports and Route Comparison. The datasheet for analysts who build routes and developers who read them, including where the table is untidy.

data applies to · NPMRDS last reviewed · 2026-09-05 owner · —

Overview

A route is a named, ordered collection of TMC segments. A TMC (Traffic Message Channel) segment is one direction of one piece of road, the unit of the NPMRDS network. A route is the input every NPMRDS analysis surface takes. Reports charts a route over time, Route Comparison cross-tabs routes against periods, and the Reports header counts them. The platform stores routes in its own table, catalogued in the Data Manager as "Routes Data".

One row is one route. It carries a name, a description, the list of TMC codes in order, a set of tags, an empty metadata object and two timestamps. It carries no geometry beyond the codes and no dates: a route is a place, and the report that uses it owns the time window. Saving a route needs a signed-in account. Reading one does not. A route's address is a link anyone can open.

basisCounts on this page are whole-table counts, all owners, at the date given in the sentence. The table changes with every save, so the live counts differ.

Which network a route belongs to

A route pins a network vintage. Its TMC codes are the codes of the map that was on screen when it was saved. The live Route Creation page draws the 2026 network, so a route made by clicking holds 2026-map codes. A route made with markers is matched by a routing service against the 2022 network, the only vintage the service resolves reliably. A July 2026 test near Albany found 2020 to 2022 resolving. The years 2016, 2018 and 2023 to 2026 returned nothing. The vintage is shown on the page as a fixed chip, not a choice.

A segment can be split, merged, lengthened or retired between vintages. A route saved against one map can therefore hold a code that a later map no longer carries. A report run on that later year charts one segment fewer. The TMC network and its vintages explains the mechanism.

Schema

The fields the Route Creation tool writes, plus the id the platform assigns. Sample values are shown only where a source records one.

FieldTypeSample valueDescription
route_idinteger—The route's id, assigned on the first save. The value Reports and Route Comparison reference, and the value in the Route Creation address (?route_id=). With the id in the address, every save updates that route.
namestring—The name typed in the save dialog. Every report that references the route inherits it. There is no per-report rename.
descriptionstring—Free text from the save dialog.
tmc_arrayJSON array of strings—The TMC codes in order, as clicked or as resolved from markers. The only geometry the route carries. Click order is stored as clicked. The tool does not sort into road order.
tagsJSON array of strings—Chips from the save dialog in an agency: and user: vocabulary, validated against the groups the saving account belongs to. A new route is seeded with the saver's own tags. Tags carry the grouping a folder would. There is no folder field.
metadataJSON object{}Always empty. The earlier tool stored start and end dates here. The current tool keeps it empty on purpose because a route carries no dates.
created_attimestamp—Stamped by the tool when the route is first saved. Not rewritten on update.
updated_attimestamp—Stamped by the tool on every save.

Marker waypoints (points) are not written. A route drawn with markers saves as a flat TMC list and reopens in TMC click mode with no pins. Editing it later means editing segments, not dragging markers.

How it is produced

  1. The Route Creation tool is reached from the Reports header's New route action. The page is one map with the tool drawn over it. A reader who cannot find the tool is looking for this action. The question was asked in August 2026.
  2. In TMC Click mode, each click on a segment adds it to the route. The TMC search box adds a segment by its 9-character code once the code resolves. The list shows each segment's code, miles and road, with a running total.
  3. In Markers mode, two or more dropped waypoints are matched to a TMC sequence by a routing service against the 2022 network. Dragging a waypoint re-resolves the whole path.
  4. Save Route opens a dialog with Name, Description and Tags. Saving writes one row: name, description, the TMC array, the tags, an empty metadata object and the timestamps. The page then navigates to the new route's address, so the button reads Update Route and later saves overwrite that row.
  5. Most rows were not drawn by a person. At the August 2026 design-era reading a service account owned 55,370 of 73,464 rows, generated in bulk. A command-line builder used by platform staff writes the same row shape and, unlike the map tool, sorts segments into road order.

Uses and limits

Reports references routes by id and binds each graph to the routes assigned to it. Route Comparison's route picker reads the same table. The Reports header's saved-routes count is a distinct count of route ids in it. The table's limits are these.

  • Duplication. About 73,464 rows carry 32,569 distinct route ids, so the same id appears in more than two rows on average. This is data debt, not a feature. A picker may show one route twice, and a count of rows is not a count of routes.
  • Stale segments. A route's TMC array can go stale when the network vintage changes, as described above. A route built for one year is not automatically valid for another.
  • Markers are not kept. Only the TMC array is saved. Waypoints do not round-trip. In marker mode the page also does not show its start and end markers, reported in September 2026.
  • Routing gaps. The routing service can return a blank segment in a resolved path. A May 2026 report names northbound I-787 near Albany. The service resolves the 2022 network only, and the year cannot be chosen.
  • Overwrite by address. With a route id in the address every save is an update, with no confirmation dialog. The button and the dialog say so, in red. Exploring from an existing route's address edits that route.
  • No dates, no folders. A route is a geometry. The time window belongs to the report's route instance. Grouping belongs to tags.

Distribution

  • Your routes. Saving needs sign-in. The routes you save are yours and carry your user: and agency: tags. The Route Creation page's All routes link, the Reports pickers and Route Comparison's picker list saved routes. See Sign in, sessions and accounts.
  • Sharing. A route's address (/route_creation?route_id=<id>) loads the route for anyone who opens it.
  • Bulk download. No page offers a download of the routes table. Whether the table can be read through the Data Manager API without signing in is not documented.

Use the map.

One map, 39 layers in 8 categories, two panels. How to turn layers on, change the view a layer colours by, read a legend block, identify a feature, change the basemap, and share the exact set of layers by address. No account is needed.

how-to applies to · Freight Atlas (www/freightatlas) last reviewed · 2026-09-07 owner · —

Before you start

Open Freight Atlas in the Freight Atlas side navigation, or arrive from a Maps Gallery tile or a shared address. The page is one full-screen map with two floating panels: Map layers, every layer by category, and Legend, one block per layer that is on. Zoom, a compass and Change base map sit at the map's edge. On a plain open every layer is off.

Steps

  1. Open a category. Under Add layers, select a category name, for example Road Network.The category expands. Its row counts its layers and, once something is on, shows a badge such as 2 on.
  2. Switch a layer on. Tick its checkbox.The header count rises, the layer appears under Active map, and a block joins the Legend.
  3. Set a layer's view. A layer whose row reads N views colours by more than one field. In its Active map row, pick from Show.The map recolours and the legend re-bins. Five layers have views; the Layer reference lists them.
  4. Read the legend block: a title, then symbols with labels, value ranges for a shaded layer, names for a categorical one, Sparse to Densest for a heat map. The info button beside the title, About this data — view the source page, opens the dataset in Data & Downloads.
  5. Identify a feature. Hover it.A popup lists the fields configured for that layer, for example Road Name, Route and AADT Value on the Freight Core Highway Network. Thirteen layers have no hover fields; the reference marks them.
  6. Find a road by name or number. Zoom in.Road names and route shields come from the basemap at street zooms, not from a layer. Default and Streets show them; Satellite and Blank do not.
  7. Find a layer by name. Type in Search 39 layers….Every category opens to show only matching rows.
  8. Take layers off. Select Remove from map, the × in an Active map row, or untick the layer. Clear all turns every layer off.
  9. Share the map. Copy the address.It carries layers= and the ids of the layers that are on, separated by |||, for example /freight_atlas?layers=2100239|||9001049. Older links with commas still work.
what the address carriesThe layers that are on, and nothing else: not the position or zoom, not the Show choice, not the basemap. Say where to look in your message.

Limits and gotchas

  • A layer that stays on. Until 2026-08-24 the New York State Freight Core Highway Network was on by default in the stored map. It drew even when nothing was ticked and appeared in neither panel. Every layer now starts off.
  • Version suffixes. The published map still reads 2024 Core Rail Freight Network v2 and Core Rail Freight Network by Class v4. The suffixes are catalogue history, not different data. The rename awaits publishing.
  • Black "last mile" lines. Until 2026-07-16 the core rail network drew Last Mile corridors in black, its darkest colour. Now National is bold navy, Statewide blue, Last Mile light.
  • No drawing order, no legend toggle. Active map keeps category order. The design's drag-to-reorder and legend hide button are not built.
  • Legend titles can differ from panel names. STRAHNET, STRACNET, the core rail layers, NYC Truck Routes and the Transearch layers are titled with the dataset's own layer name. A layer with views is titled with the view, so Traffic Volume & Road Attributes appears as AADT. Match blocks by their labels.
  • Bundled context. Pipeline System draws REDC regions behind the pipelines; USDA Apple Orchard Locations draws counties, REDC regions and rail lines with the orchards.
  • One year. The Transearch layers draw the 2021 base year of the TRANSEARCH 2023 release. No 2050 forecast layer is on the map.

Troubleshooting

A layer draws that I did not turn on

Until 2026-08-24 this was the Freight Core Highway Network, on by default even when a shared address asked for other layers. All 39 layers now default off. Reload at /freight_atlas with no parameters; if a layer persists, report it with the address.

I cannot turn a layer off

Three controls turn a layer off: its checkbox, Remove from map in its Active map row, and Clear all. The July 2026 report could not be reproduced. The likeliest cause was the default-on network above, which no control could remove because none had turned it on.

The roads have no route numbers

Shields and names are drawn by the basemap at street zooms. Zoom in. The default basemap was switched to a road-oriented style with shields in July 2026 for this reason. Under Satellite or Blank, choose Default or Streets.

I cannot find "Road Performance Measures"

Renamed on 2026-07-27. It colours roads by volume and attributes, not performance measures, so it is now Traffic Volume & Road Attributes under Road Network, views unchanged.

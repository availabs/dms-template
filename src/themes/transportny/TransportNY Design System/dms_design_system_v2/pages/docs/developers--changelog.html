API changelog.

Dated changes to the two APIs, the download routes and the developer documentation, newest first. For anyone whose script stopped working, or who wants to know which form of a path is current.

log applies to · Developers last reviewed · 2026-09-08 owner · —

Each entry carries one of three labels. Platform: sign-in, hosts or a page changed and no request grammar moved. API: an endpoint, a path, a parameter or a download format changed. Docs: a developer page was published or superseded. Changes with no sourced day sit under Undated; no day is invented. One change is planned and not yet dated: the Batch Reports API retires when Route Comparison is released, see its status note. Methodology changes to the numbers themselves are in Methodology changes.

2026-09-02 · Platform

TSMO and the Freight Atlas moved onto the landing page's origin. One sign-in now carries across the products that share it; before, each product was a separate session. The sign-in token is scoped to the origin that issued it. NPMRDS keeps its own address until it moves. No API path changed. See Sign in, sessions and accounts.

2026-08-24 · API

The Macro View download route stopped offering JSON, which the export pipeline had never been able to write, and now refuses GeoJSON as a matter of policy. Both refusals are errors that name the format. CSV and GPKG remain; a Shapefile is accepted by the route but not offered by the builder. See The Macro View package.

2026-07-27 · Platform

Downloads were generated for the 23 Freight Atlas dataset versions that had none, as CSV, ESRI Shapefile and GPKG, so every Freight Atlas version has a file. The TSMO Data & Methodology page's Downloads & API band was relinked: its bulk-tables card now opens the excessive-delay series source page, whose download is a CSV per year, and its API card opens the API guide. A card that linked out to the raw NPMRDS provider was removed. See Bulk downloads and formats.

2026-02-04 · Docs

The Batch Reports API reference was published: the endpoint POST https://graph.availabs.org/batchreports/npmrds2/982, the request and response bodies, four example calls, the column and source codes, and the two page routes that require sign-in. This documentation's Batch Reports API page carries it, with the retirement note.

2025-09-24 · Docs

The python client examples were published: installation from the client's repository and a script that saves the TRANSCOM events query to a CSV. See The python client.

2025-09-10 · Docs

The worked example was published: the TRANSCOM events query against https://graph.availabs.org/graph, written with the uda root and the viewsById and dataByIndex casing that the site itself uses. It is the form this documentation treats as current. See Worked examples.

2025-08-27 · Docs

The Data Manager API reference was published: Get Length by ViewId, Get Attributes By ViewId, and the options object with filter, exclude, gt/gte/lt/lte, like, groupBy, orderBy and aggregatedLen. It was written with the root dama and the casing viewsbyId and databyIndex, which this documentation records as the legacy form. See The legacy form.

2024-07-23 · Docs

The Batch Reports tool page was published, with the format of the CSV the tool imported: no header row, four columns, TMCs joined with a pipe. See The legacy pages.

2024-04-04 · Docs

The NPMRDS appendix's APIs section, marked draft, listed three services in one line each: an NPMRDS API "powering the reporting view", a PM3 API "powering macro view", and a RIS API with no description. The Developers hub supersedes it.

Undated · API

  • The uda root was added to the site's request builder as "a new route that can accept filter and calculate length". The code carries no date; the 2025-09-10 worked example is the earliest dated use.
  • The Batch Reports endpoint, POST /batchreports/:pgEnv/:viewId, was added to the data server. The code carries no date; its reference is dated 2026-02-04.
  • The per-version download generation, which writes CSV, ESRI Shapefile, GeoJSON and GPKG with ogr2ogr and records the addresses on the view, predates the 2026-07-27 generation pass. The code carries no date.

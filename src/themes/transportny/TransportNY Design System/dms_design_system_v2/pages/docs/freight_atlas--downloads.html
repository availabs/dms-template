Freight Atlas · how-to

Download freight data.

Every layer on the map draws a dataset in Data & Downloads, the Freight Atlas catalog. How to find a dataset, read its source page, pick a version and a format, what still asks for a login, and the rule that keeps the site's figures in step with the plan.

how-to applies to · Freight Atlas (www/freightatlas) last reviewed · 2026-09-07 owner · — requires sign-in

Before you start

Data & Downloads in the Freight Atlas side navigation opens the catalog filtered to the Freight Atlas category. It is meant to be public, but at the 2026-07-29 check a visitor without an account saw the sign-in page. See What needs a login. From the map, the legend's info button lands on a dataset's source page directly.

Steps

  1. Open Data & Downloads.The catalog header counts what is listed, "N datasets · N categories". A rail on the left starts with All datasets and lists the categories with counts. The Freight Atlas category is selected and its sub-categories appear under it.
  2. Narrow the list. Select a sub-category such as Rail Network or Truck Parking, or type a name in Search datasources.The list shows the matches. The sort button flips A to Z and Z to A. The view switcher offers cards, a grid, or a table with Name, Type, Category and Description.
  3. Open a dataset by its name.Its source page opens on Overview. The tab bar reads Overview · Table · Map, with Admin for administrators. Overview shows Description, At a glance (Type, Columns, Versions, Update interval, Created, Updated), Categories, Columns and Versions.
  4. Read the data dictionary. The Columns table lists every field with Column, Type, Description and Req.The provenance note in Description names the original source and its vintage.
  5. Download. Under Versions, find the version you want and select Download.With one file it downloads at once; with several it opens a menu of formats: CSV, ESRI Shapefile, GeoJSON, GPKG. Each is a zip.
  6. Look before you download. Table shows the rows; Map draws the geometry.On these two tabs a version selector appears and starts at the latest version.

What needs a login

Nothing, by design. In practice, at the 2026-07-29 check, opening the catalog without an account showed the sign-in page, from the Freight Atlas and from the landing page alike. The cause was found in the catalog's permission check, not in a decision to gate it, and the record closes without deciding whether the catalog stays public. Until that changes, sign in, or ask for the file through Help and feedback. The map, the gallery and the plan pages are public. See Data & Downloads asked me to sign in.

Formats and what was generated

A download exists only where a file was generated for that version. On 2026-07-27 the 23 Freight Atlas versions without one were generated as CSV, ESRI Shapefile and GPKG; the 28 versions that already had files carry GeoJSON as well. Every Freight Atlas version now has a download. GPKG is the GeoPackage format. The catalog's design listed XLSX; the live source page does not offer it.

The API for developers

The same catalog is readable through the Data Manager API, which the home names beside the download formats. Start with the developer Quick start and the Data Manager API reference. Both are planned pages.

The figures agree with the plan

Where the 2024 State Freight Plan publishes a figure, the Freight Atlas shows the plan's figure. The rule dates from 2026-08-25, when the home's mode-share chart, computed from the TRANSEARCH table, disagreed with the plan and was replaced by the plan's own values. The layers and datasets still carry the underlying data. Quote a headline from the home or the plan; quote a layer's data from its dataset, with its version.

Limits and gotchas

  • Seven layers draw datasets with no public catalog entry: the state and national freight highway networks, STRAHNET, the two Transearch totals layers, and the two licensed layers. See The sources.
  • Update interval is blank on every Freight Atlas dataset: each is a one-time upload unless its description says otherwise. The catalog's modified dates are edit dates, not data vintages.
  • A dataset can have several versions. The download menu belongs to a version; check the version's name before you cite it.
  • The home says 52 datasets; the catalog header counts what its filter lists. Neither is the layer count, 39.
  • A bare /freight_data address, without the category, lists every dataset the catalog holds, Freight Atlas or not.

Troubleshooting

A dataset has no Download button

Until 2026-07-27, 23 Freight Atlas versions had no generated file, so their source pages showed no button. All were generated that day. If a version still shows none, report it with the dataset and version name.

A category shows no datasets

Until 2026-07-17 a category with an ampersand in its name, Economy & Demand, Environment & Equity, lost the rest of its name in the address and matched nothing. Fixed in the catalog. An empty category today means no dataset is filed under it.

"Browse the catalog" did nothing

The button on the About page was a placeholder and was removed in July 2026. The way in is Data & Downloads in the side navigation, on every Freight Atlas page.

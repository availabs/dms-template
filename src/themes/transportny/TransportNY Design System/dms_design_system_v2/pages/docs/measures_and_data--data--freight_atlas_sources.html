Freight Atlas sources.

An index of the datasets behind the Freight Atlas map: what each holds, where it came from, and which map layer draws it. For planners and analysts who need to cite a layer or download its data, and who want to know how the map stays in step with the 2024 State Freight Plan.

data applies to · Freight Atlas (www/freightatlas) last reviewed · 2026-09-05 owner · —

Overview

The Freight Atlas is the interactive companion to the 2024 New York State Freight Plan. The plan is the provenance frame for every source here. The plan's consultant compiled a data inventory of 57 sources for the plan's maps and figures. Those sources, uploaded to the Data Manager and categorised "Freight Atlas", are the datasets this page indexes. The Maps Gallery rebuilds each of the plan's 33 maps from the same layers.

The plan's commodity figures come from TRANSEARCH, S&P Global's commodity-flow database. The plan uses its 2023 release with a 2021 base year and a 2050 forecast. The home page's headline is 936.5 million tons moved across all five modes in the 2021 base year, forecast to grow 34 % by 2050. An earlier sub-line read "S&P TRANSEARCH 2023", which readers took for a data year. It was reworded in July 2026.

Where the plan publishes a figure, the Freight Atlas shows the plan's figure. The rule dates from August 2026, when a mode-share chart that derived its shares live from the TRANSEARCH table disagreed with the plan. It was replaced by the plan's own values. By tons: truck 68.6 %, water 17.0 %, rail 10.7 %, pipeline 3.2 %, air 0.3 %. By value: truck 75.9 %, water 5.6 %, rail 14.7 %, pipeline 0.5 %, air 3.0 %. The map layers still draw the underlying data.

basisFigures on this page are statewide and follow the plan's 2021 base year unless a source states its own year. Layer and source counts are at the 2026-09-05 reading of the live map and the 2026-09-04 reading of the catalog.

Coverage and vintage

For a Freight Atlas source, vintage means the year of the data inside it, not the date it was uploaded. Each source carries its own. The vintages the catalog and the layer titles state:

  • border-crossing truck volumes 2022 · airport cargo tons 2022 · dairy cow counts 2021 · REDC population 2012 and 2022
  • road condition exported 2020 · crude-oil rail terminals active 2017 to 2018 · bottleneck segments on the 2021 network
  • truck crash density 2018 to 2022 · business locations 2019 (layer titles)
  • TRANSEARCH flows: the 2021 base year with a 2050 forecast. The map offers a 2021 to 2050 vintage toggle

The Data Manager records an update interval per source. None of the 30 readable sources declares one at the 2026-09-04 reading, so treat each as a one-time upload unless its source page says otherwise. The catalog's modified dates run from 2026-06-29 to 2026-08-10 and are edit dates, not data vintages. The source page's version selector shows whether a source has more than one version.

The sources

The Data & Downloads catalog advertises 52 datasets. This index covers the 30 Freight Atlas sources whose catalog entry was publicly readable at the 2026-09-04 reading. The July 2026 metadata pass covered 35 Freight Atlas sources; the five not readable to the public are not listed here, and the catalog's own count differs because it counts versions and sub-categories. The tables follow the live map's eight layer categories. The catalog groups sources differently: Regions, Freight Facilities, Pipeline, Air Cargo, Truck Parking, Commodity Flows, Economy & Demand, Environment & Equity, Performance and Bridges. A layer whose source is not publicly readable is listed with "—" in the Source column. Every source is a GIS dataset. The Type column gives its geometry.

One readable source has no layer on the live map: NY State Bridge Inventory. It is a point layer of bridges with type, material, condition and minimum vertical clearance. A flag marks bridges within 600 feet of the Freight Core Highway Network.

How it is produced

  1. Each dataset is uploaded to the Data Manager as a GIS dataset and categorised "Freight Atlas". The description carries the plan's inventory code and a provenance note. Fourteen plan datasets were uploaded on 2026-07-10 to close gaps the crosstab found.
  2. Each source gets a symbology: a styled map layer with a legend and the fields shown on hover. The live map holds 39 layers in eight categories. Nine of them were added in July 2026 as "gap layers" for plan figures the map did not yet reproduce.
  3. The crosstab indexes every plan figure to its inventory source, its Data Manager source and its layer. At 2026-07-10, 14 of the 33 plan maps were reproducible from live layers, 11 had data loaded but no layer, and 8 needed data. The gap list names what is still outside the catalog: crude-oil rail terminals (EIA), border-crossing volumes and TransBorder flows (BTS), airport traffic, and freight-project locations.
  4. Download files are generated per dataset version. On 2026-07-27 the 23 versions that lacked one were generated as CSV, Shapefile and GeoPackage.

Uses and limits

The sources exist to draw the map, to rebuild the plan's maps in the Maps Gallery, and to be downloaded. Three limits matter when citing them. First, plan-published figures and live layer data are different things. Quote the plan's number from the home or the plan itself, and the layer's data from its source page. Second, downloads existed for some datasets only until 2026-07-27, when the missing ones were generated. If a source page shows no download, the file may not have been published yet. Third, the Data & Downloads catalog showed a sign-in page to anonymous visitors in July 2026, although the home says "No login". The cause was a permission check, not a deliberate gate. Whether the catalog is meant to be public awaited a decision. Two layers rest on licensed data (Data Axle business points, ATRI parking clusters). The crosstab flags their redistribution terms as unconfirmed.

Distribution

  • Data & Downloads. The catalog lists every dataset with a category rail and search. The home names CSV, GeoJSON, Shapefile and GeoPackage as the download formats. The source page design adds XLSX. See Download freight data.
  • The source page. Tabs Overview · Table · Map · Metadata, with a version selector. Overview carries the description, categories, columns and downloads. Metadata carries the data dictionary.
  • The map. Each layer offers a per-layer download and feature popups.
  • Data Manager API. The same catalog is readable through the API described in Data Manager API.

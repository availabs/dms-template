Start a report from a template.

The Reports page offers 12 templates in five question types. Each arrives with its graphs already wired; you supply the route and, for some, the date to count back from. Here is what the page shows, how to pick a template, and what you get.

how-to applies to · NPMRDS last reviewed · 2026-09-05 owner · —

Before you start

Open Reports from the NPMRDS side navigation. No account is needed to open a template and read it. You need a saved route, yours or a colleague's, or a generated one; Create a route if you have none. Know which question you are asking: the Template reference has one entry per template.

Steps

  1. Read the header row. It holds the view toggle Templates | All reports, a search bar reading Find a report — search N by name, road, route or description…, Create Report and New route.Below it the band Start from a question, not a blank page. counts 12 templates in 5 question types.
  2. Read the five groups: Before & after, Floating car, Events, Change over time and Behavioral. Each card carries the template's name, a short description, a difficulty chip on 9 of the 12 (beginner, intermediate or advanced) and the link use template →.
  3. Pick the template that matches your question, using the table below.
  4. Select use template →.The template's page opens. Its routes are not fixed, so an Add Routes dialog opens at once and asks for exactly the number of routes the template needs, for example Select 1 more (0/1). Bi-directional asks for two, one per direction.
  5. Find your route by name, by Mine, or through Browse by tag, and tick it. If the dialog shows Viewing as of, set the date the template's periods count back from; it starts at the latest date with data.The button reads Add 1 Route.
  6. Select it.The report renders with your route in every period the template defines. The address now carries ?routes= and, where an anchor date applies, asOf=.
  7. Read the header: the title, a one-line purpose, the published pill, and a data line such as complete through a month. Then read the graph cards top to bottom; the template reference says how.
  8. To move the periods, change Viewing as of in the header. Use latest available resets it.
  9. Copy the address to keep or share this filled view. See Share, print and publish a report.

What you get

A shared template filled with your route. The route choice and the anchor date live in the address, not on the page, so the same template serves everyone and nothing is written to your account. You do not get a copy you can edit. To add graphs, change measures or keep a report of your own, select Create Report and follow Build and edit a report.

Limits and gotchas

  • Templates count back from the anchor date. "Current Year" means the year that date falls in, so a January anchor gives a thin current year. Set the anchor to the end of the period you care about.
  • The latest date with data sits a few weeks behind today. An anchor inside that gap gives blank graphs.
  • Three templates carry no difficulty chip.
  • The All reports cell of the toggle shipped inert on 2026-09-02; the list page it points to was published on 2026-09-04. The list page is at /reports/list; the toggle's All reports cell is its entry from the Reports page.
  • The side navigation's Reports item was recorded as pointing at the page's old address after the 2026-09-02 rename. The side navigation's Reports item opens /reports.

Troubleshooting

The page reads "Select routes to view this report."

The address has no route, or fewer than the template needs. The dialog reopens on reload; pick the routes again.

Every graph is blank

Check Viewing as of. If it is later than the data line's complete through month, select Use latest available. If a route is one segment long, thin coverage can also leave a window empty; see Data coverage.

A 2025 date gave "route does not exist"

That message came from the earlier tool's template loader and was resolved there. On the current pages a template never stores a route; if a report cannot find one, reopen it from the Reports page and pick the route again.

Build and edit a report.

A report is a page: a header, a Routes rail you see only while editing, and one card per graph. Routes carry dates; graphs carry the measure, the time of day, the days of the week and the comparison mode. Here is how to add both and tune them.

Before you start

Sign in. Open a report you own, or make one with Create Report on the Reports page, which opens the new page in edit mode. Edit mode is the page's /edit/ address; the header button reads Edit to enter it and Done to leave. In edit mode the Routes rail appears and every graph card gains a row of pills, its Quick Controls. Readers never see either.

Steps

  1. Select Edit.The address gains /edit/. The header's title, purpose and kicker become fields, the rail appears, and each card shows its pills.
  2. Select Add Route, find a route (see Find, edit, tag and share routes) and select Add N Routes.Each route becomes an expanded row: colour dot, name, and "N TMCs · N mi · No dates set · 0 graphs".
  3. Set the window. Enter From and To. − 1 year and + 1 year move both dates and keep the length.The row saves after a moment and the dates show in its meta line.
  4. To reuse a window, select the copy icon on one row and the paste icon on another, or paste into all (N) from the strip that appears.
  5. To tie one route's dates to another's, select Derive from another route instead, pick Derive From and a Pattern such as Offset by whole periods.The row reads "Derived from …" and recomputes whenever the base route's dates change. Today (view time) is always offered as a base.
  6. For a before-and-after comparison add the same route twice, one row per period, and rename each row with the pencil so it reads as a legend entry. Names must be unique within the report.
  7. Set each row's colour from its dot. The colour follows the route onto every card it feeds.
  8. Select Add Graph. Tick the routes under Routes for this graph; choose a shape under What to show; set Measure, Resolution and Comparison Mode; under When pick a time-of-day preset and the days. Select Add Graph.A card appears at the bottom, drawing the chosen routes. Its pills read the route, the measure, the window, the aggregate and Overlay or Diff.
  9. Change a card from its pills. Routes on this card adds or drops routes; the measure pill changes the measure; the When pill sets the hours and days; the aggregate pill sets the resolution; the mode pill switches Plain and Difference. To the left, arrows move the card, a width pill sets its column span, and a legend pill moves the legend.
  10. Fill the header: title, a one-line purpose, the kicker and meta line, tags, and a Data link if a download exists. The Data source line takes the data-freshness words readers see.
  11. To make the report a reusable template, open Report settings in the rail and turn on Dynamic Report. Routes are then picked by whoever opens the report, and the rail offers Add Route Slot instead of Add Route.
  12. Select Done.The page publishes and opens in reading mode with a published pill.

What saves when

Two stores are in play. The Routes rail writes each change, a name, a window, a colour, an added or removed route, to the report's own route record the moment you make it. Graph cards, header text and layout are the page's draft until Done publishes them. A route change therefore reaches readers at once, while a new graph waits for Done.

Limits and gotchas

  • Difference needs exactly two routes on the card. The dialog warns "Difference mode compares exactly two routes"; the pill disables the option until the count is two. The result is anchor minus the other.
  • A Map has no When at creation and no aggregate; a Table's Route Compare and Reliability extras work only at Summary resolution, and Reliability only for a peak-period window in a year with published values.
  • Dates belong to the row; hours and days belong to the card. Two cards can read the same row through different windows.
  • A row's rename is local to this report. The saved route keeps its name.
  • A route from one map year can lose a segment in another year's data; see how routes bind to a vintage.
  • Report delay measures use the excessive-delay threshold: the greater of 20 mph or 60 % of the posted limit, weighted by AADT. See Excessive delay.

Troubleshooting

I do not see the Routes rail

You are reading, not editing. Select Edit. If there is no Edit, sign in; if there still is none, the report is not yours to edit.

A new graph is blank

Wait a few seconds and reload; a card can render empty right after it is added. Then check the row has dates, the card has routes, and the window is not inside the data lag or a weekend-only mask on a weekday route.

"A route named X already exists."

Row names are unique per report. Add the period to the name.

Find an incident.

Find any TRANSCOM event on New York roads by region, county, time period, category or keyword. Read what the results table says about its delay, and open the event's page. No account is needed.

how-to applies to · TSMO (www/tsmo) last reviewed · 2026-09-05 owner · —

Before you start

Open Explorers › Incident Search. The search covers the whole TRANSCOM feed filtered to New York, every category including construction, about 3.7 million events since 2015. Attributed delay and cost exist on about 18.5 % of them. Facets react as you set them; there is no submit button.

Steps

  1. Open Incident Search.You see the facet bar, one keyword box, and Matching events: a count and a table, one row per event.
  2. Pick a region.The count and table update. The county options narrow to that region.
  3. Pick a county, if you have one.
  4. Pick a year, or several. This page keeps multi-select because it is a query tool. Add a month to narrow further.The count updates with each pick.
  5. Pick a category, if you want one kind of event. Every category is offered here, Construction included.
  6. Type a word in the keyword box, for example a road name or an event id.Rows whose facility, description, category, county or event id contain the word remain. One box searches all five columns.
  7. Read the table. Rows are ranked by attributed delay. A row with a measured footprint shows delay and cost; a row without one shows — in both and still appears.
  8. Select a row's view link.The event's page opens. See Read an incident page.

Settings

What the delay and cost columns mean

Delay is the event's footprint: the vehicle-hours lost on its affected segments above what those segments carry on an ordinary day. A footprint is computed only where probe speeds around the event fell below that baseline on matched segments. About 18.5 % of events have one. The rest show —, which means no measured footprint, not zero delay. An event list never implies that every event delayed traffic. See Delay attribution.

Cost is the footprint priced at an interim flat $20 per vehicle-hour. The page says it will re-base to the class-weighted value of time as that data lands. Do not compare it with a dollar figure from a page on the other basis. See Which pages show which basis.

Limits and gotchas

  • Facets combine. Region and category and keyword together can leave nothing.
  • One keyword box, no per-field search. A road name also matches descriptions that mention it.
  • The feed is multi-state; this page keeps New York. Category names are the feed's own.
  • There is no map on the search page. The event's page carries the location map.
  • Ranking by delay puts footprinted events first; a recent event with no footprint sits low.

Troubleshooting

No results

Clear one facet at a time, starting with the keyword and the month. A county with a year it had no events in returns nothing.

Delay and cost show a dash

The event has no measured footprint. That is the case for about four events in five. It is not an error and not a zero.

The county list is short

Counties narrow to the region and years already chosen. Clear the region to see every county.

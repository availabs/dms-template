Quick start: your first requests to the platform.

In about 10 minutes you mint a sign-in token, count the rows of a public dataset without one, read five rows, and fetch a generated file. This page assumes a terminal or a browser and nothing else. Only the token step needs an account.

What you will do

You work against one dataset, the TRANSCOM events table, and ask it the two questions every query starts with: how many rows match, and what are they. Then you read a view's download links and fetch one file. Every request is a plain HTTPS GET, so the same steps work from a browser address bar, curl, or any language.

Before you start

Two hosts. Data reads go to https://graph.availabs.org. Sign-in goes to https://dmsserver.availabs.org, the same server the site signs in against. Reads of published data need no token, so steps 2 to 6 work without step 1. Do step 1 when you need an account for the command-line tools, for listing, or for editing a dataset's description. Keep a URL encoder to hand; the API's paths travel inside a query string.

Steps

  1. Mint a token. Post your account's email and password, and the site's project name, to the sign-in route. 
    POST https://dmsserver.availabs.org/login
Content-Type: application/json

{ "email": "<your email>", "password": "<your password>", "project": "npmrdsv5" }

→ 200 { "user": { "token": "<JWT>", … } }
    The token lasts about 6 hours. Send it as the Authorization header on later requests. Never put it in a URL, a shared script or a commit.
  2. Write the path that asks for a length. A request is a JSON array of paths. This one names the root, the data environment, the view, an options object as a JSON string, and the word length. 
    [["uda","npmrds2","viewsById",1947,"options",
  "{\"groupBy\":[],\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"exclude\":{},\"normalFilter\":[]}",
  "length"]]
  3. URL-encode the array and put it after paths= on the graph route, with method=get. 
    https://graph.availabs.org/graph?paths=%5B%5B%22uda%22%2C%22npmrds2%22%2C%22viewsById%22%2C1947%2C%22options%22%2C%22%7B%5C%22groupBy%5C%22%3A%5B%5D%2C%5C%22filter%5C%22%3A%7B%5C%22month_year%5C%22%3A%5B%5C%2206-2025%5C%22%5D%2C%5C%22region_name%5C%22%3A%5B%5C%22Region%201%20-%20Capital%20District%5C%22%5D%7D%2C%5C%22exclude%5C%22%3A%7B%7D%2C%5C%22normalFilter%5C%22%3A%5B%5D%7D%22%2C%22length%22%5D%5D&method=get
    The response mirrors your path and ends in the answer. 
    {"jsonGraph":{"uda":{"npmrds2":{"viewsById":{"1947":{"options":{
  "{\"groupBy\":[],\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"exclude\":{},\"normalFilter\":[]}":
    {"length":1262}}}}}}}}
    1,262 events matched June 2025 in Region 1 when the example was recorded on 2025-09-10. The live table recomputes.
  4. Read the first five rows. Replace length with dataByIndex, an index range, and the columns you want. Indices count from 0 and the range is inclusive. 
    [["uda","npmrds2","viewsById",1947,"options",
  "{\"groupBy\":[],\"orderBy\":{\"cost\":\"desc nulls last\"},\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"exclude\":{},\"normalFilter\":[],\"meta\":{}}",
  "dataByIndex",{"from":0,"to":4},
  ["event_id","facility","event_type","start_date_time","cost"]]]
    Each row arrives under its index, one key per column you asked for. Dates and nulls come wrapped as atoms. 
    "dataByIndex": {
  "0": {
    "event_id": "ORI1237917919",
    "facility": "I-90",
    "event_type": "Disabled vehicle",
    "start_date_time": { "$type": "atom", "value": "2025-06-25T17:01:58.000Z" },
    "cost": "78062"
  },
  "1": { … }, "2": { … }, "3": { … }, "4": { … }
}
  5. Read a view's download links. Generated files hang off the view, not the rows. Ask for the view's metadata attribute; its download key maps each format to a file URL. 
    [["uda","npmrds2","views","byId",3488,"metadata"]]
    The value is one atom holding the view's metadata. Under download, a key per generated format. A stored address is either absolute or begins with the literal $HOST, which the site replaces with the data host, https://graph.availabs.org; do the same before you fetch.
  6. Fetch the file. This one is the excessive-delay series, generated on 2026-07-27 as a zip of nine CSVs, one per year, 4,927,052 rows, about 143 MB. Open it or fetch it with any HTTP client; no token is needed. 
    https://availabs-bucket.files.availabs.org/npmrds2/s_2039/excessive_delay_v2_series_s2039_v3488_CSV.zip
    Read the Excessive-delay series datasheet before you use it: 2019 and 2020 are not in the run, and the latest year is partial.

What you now have

A token you can reuse for 6 hours, the length-then-rows pattern that every query on the platform follows, a row with atoms unwrapped, and a generated file on disk. You also have the three things a request needs: the data environment, the view id from the dataset's source page or datasheet, and the column names from its schema table.

Count, read, filter and group a dataset.

The TRANSCOM events query in full, then two variants, a narrowed filter and a grouped count, then the same query from the python client. Every example shows the exact path sent. This page assumes you have run the quick start and know the length-then-rows pattern.

Before you start

All examples read the TRANSCOM events table in the npmrds2 environment, for June 2025 in Region 1. The datasheet's schema names the columns used here: event_id, event_type, facility, region_name, month_year, cost, vehicle_delay, congestion_data. No token is needed. Each path below goes into https://graph.availabs.org/graph?paths=…&method=get, URL-encoded, as the quick start showed. The recorded counts and rows are from 2025-09-10; the live table recomputes.

Steps

  1. Write the options string. Two filters, nothing grouped, nothing excluded. 
    {"groupBy":[],"filter":{"month_year":["06-2025"],"region_name":["Region 1 - Capital District"]},"exclude":{},"normalFilter":[]}
  2. Ask for the length. 
    [["uda","npmrds2","viewsById",1947,"options",
  "{\"groupBy\":[],\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"exclude\":{},\"normalFilter\":[]}",
  "length"]]
    {"length":1262} at the end of the mirrored path.
  3. Ask for rows. Add an order, ask for indices 0 to 4, and list the columns. This is the example's own column list. 
    [["uda","npmrds2","viewsById",1947,"options",
  "{\"groupBy\":[],\"orderBy\":{\"cost\":\"desc nulls last\"},\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"exclude\":{},\"normalFilter\":[],\"meta\":{}}",
  "dataByIndex",{"from":0,"to":4},
  ["event_id as event_id","reporting_organization as reporting_organization","event_class as event_class",
   "start_date_time as start_date_time","close_date as close_date","facility as facility",
   "event_duration as event_duration","event_type as event_type","lanes_total_count as lanes_total_count",
   "lanes_affected_count as lanes_affected_count","lanes_detail as lanes_detail","lanes_status as lanes_status",
   "description as description","direction as direction","event_location_latitude as event_location_latitude",
   "event_location_longitude as event_location_longitude","recoverytime as recoverytime","f_system as f_system",
   "vehicle_delay","cost as cost"]]]
  4. Read the first row. The keys are the attribute strings exactly as sent; dates and nulls arrive as atoms. 
    "0": {
  "event_id as event_id": "ORI1237917919",
  "reporting_organization as reporting_organization": "NYSDOT TMC - Albany",
  "event_class as event_class": "Incident",
  "start_date_time as start_date_time": { "$type": "atom", "value": "2025-06-25T17:01:58.000Z" },
  "close_date as close_date": { "$type": "atom", "value": "2025-06-25T17:14:16.000Z" },
  "facility as facility": "I-90",
  "event_duration as event_duration": "0 - 00:13",
  "event_type as event_type": "Disabled vehicle",
  "lanes_total_count as lanes_total_count": 4,
  "lanes_affected_count as lanes_affected_count": { "$type": "atom", "value": null },
  "lanes_detail as lanes_detail": "right shoulder",
  "lanes_status as lanes_status": "closed",
  "direction as direction": "westbound",
  "f_system as f_system": 1,
  "vehicle_delay as vehicle_delay": "4072.8296476032688",
  "cost as cost": "78062"
}
    The highest-cost event that month in Region 1 was a disabled vehicle on I-90, 13 minutes, $78,062 of delay cost by the platform's estimate.
  5. Change the columns. The same options with two attributes returns the congestion detail per event. 
    [["uda","npmrds2","viewsById",1947,"options",
  "{\"groupBy\":[],\"orderBy\":{\"cost\":\"desc nulls last\"},\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"exclude\":{},\"normalFilter\":[],\"meta\":{}}",
  "dataByIndex",{"from":0,"to":4},
  ["event_id","congestion_data"]]]
  6. Page through the rest. Move the range, {"from":5,"to":9} and so on, until to reaches the length minus one. Indices past the end return nothing.

A filtered query and a grouped count

Narrow with exclude and a comparison

Drop construction events and keep only those with a cost of $50,000 or more. Ask for the length first, then the rows; both take the same options string. The response has the shape of step 4; its count depends on the live table.

[["uda","npmrds2","viewsById",1947,"options",
  "{\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"exclude\":{\"event_type\":[\"Construction\"]},\"gte\":{\"cost\":50000},\"orderBy\":{\"cost\":\"desc nulls last\"}}",
  "dataByIndex",{"from":0,"to":9},
  ["event_id","event_type","facility","cost"]]]

Group and count

Group the month's events by type and count each group. Every attribute is then a grouped column or an aggregate with an alias. Order by position 2, the count. For the length of a grouped query, set aggregatedLen so the count is of groups, not rows.

[["uda","npmrds2","viewsById",1947,"options",
  "{\"groupBy\":[\"event_type\"],\"aggregatedLen\":true,\"filter\":{\"month_year\":[\"06-2025\"],\"region_name\":[\"Region 1 - Capital District\"]},\"orderBy\":{\"2\":\"desc\"}}",
  "dataByIndex",{"from":0,"to":19},
  ["event_type","count(1) as events"]]]

The python client

The client is installed from its repository, not from a package index. Cloning it and running the sample script saves a TRANSCOM query to a CSV.

git clone git@github.com:availabs/dama-api-client-py.git
cd dama-api-client-py
python3 transcom.py

The sample script sends the options and columns of step 3 and writes rows 0 to 100 to transcom_data_direct.csv in one call.

#!/usr/bin/env python3
"""
Example usage of the Datamanager API Client
"""

import json
from datamanager_api_client import (
    fetch_data_from_api,
    parse_api_response_to_csv,
    save_csv_to_file,
    fetch_and_convert_to_csv
)

def main():
    view_id = 1947

    filters = {
        "groupBy": [],
        "orderBy": {"cost": "desc nulls last"},
        "filter": {
            "month_year": ["06-2025"],
            "region_name": ["Region 1 - Capital District"]
        },
        "exclude": {},
        "normalFilter": [],
        "meta": {}
    }

    columns = [
        "event_id", "reporting_organization", "event_class", "start_date_time", "close_date",
        "facility", "event_duration", "event_type", "lanes_total_count", "lanes_affected_count",
        "lanes_detail", "lanes_status", "description", "direction", "event_location_latitude",
        "event_location_longitude", "recoverytime", "f_system", "vehicle_delay", "cost"
    ]

    try:
        print("\n" + "="*50)
        print("Fetch and convert in one step...")
        csv_direct = fetch_and_convert_to_csv(view_id, filters, columns, 0, 100, "transcom_data_direct.csv")
        print("Direct CSV conversion completed!")

    except Exception as e:
        print(f"Failed to fetch or convert data: {e}")

if __name__ == "__main__":
    main()

The published example stops there. It does not show how the client picks its host or its data environment, whether it can send a token, or the signatures of fetch_data_from_api, parse_api_response_to_csv and save_csv_to_file. Those are documented in the repository itself, which needs access to read; this page does not restate them. The clone address uses SSH; a GitHub key is needed, or the HTTPS form of the same address.

Limits and gotchas

  • The options object is encoded twice: JSON inside the path, then the whole path as a URL. Inner quotes are \".
  • The index range is inclusive: {"from":0,"to":4} is five rows. The count is what length said, minus one, at the top.
  • An alias is part of the key. Ask for "cost as cost" and read "cost as cost"; ask for "cost" and read "cost".
  • Numeric columns can arrive as strings, as "cost": "78062" does. Parse before you sum.
  • like compares lower-cased text and adds no wildcards. Write "I-9%" yourself.
  • Counts drift. The table is refreshed, so 1,262 is the 2025-09-10 figure, not a constant.

Troubleshooting

dataByIndex comes back empty

The range is not of the form {"from": x, "to": y}, or it lies past the length. The reference's own note: the indices parameter must specify a valid range. Ask for length with the same options and re-page.

The request fails on a column name

An attribute is not a column of the view. Names are not checked before the query runs. Copy them from the datasheet's schema table or the source page's Columns list; watch for aliases that hide a typo.

The filter is ignored

The options value was sent as an object rather than a string, or its quotes were not escaped, so the server read an empty options object. The reference's note: ensure the options parameter is properly JSON stringified. Compare your encoded URL to step 2 of the quick start.

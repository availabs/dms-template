Batch Reports API.

One REST endpoint that takes a list of routes as TMC lists with time windows, and a list of columns, and returns speed, travel time and hours of delay per route and column. It is the service behind the earlier Batch Reports tool and retires with Route Comparison. For developers who still call it, and for anyone porting a script.

reference applies to · Developers last reviewed · 2026-09-08 owner · — retires with Route Comparison

Status

retires with Route ComparisonThe endpoint, the two pages that call it and the table of saved batch reports are the earlier Batch Reports tool. Route Comparison replaces the tool; when it is released the endpoint is retired with it. Until then this page describes the endpoint as its reference of 2026-02-04 and the server code have it. Saved batch reports are not carried over.

The endpoint

POST https://graph.availabs.org/batchreports/npmrds2/982
Content-Type: application/json

The server route is /batchreports/:pgEnv/:viewId. The two segments name the data environment and the travel-time view the numbers are computed from; the reference gives them as above and no other values are documented. The body is JSON text. Times are turned into 5-minute epochs on the server; the first column in columns is the base.

Request body

{
  id: string,              // UUID for this request batch
  routes: [
    {
      uuid: string,        // unique identifier for this route instance
      rid: number,         // route ID
      name: string,        // route name
      tmcs: string[],      // array of TMC codes
      startTime: string,   // "HH:mm:ss" format
      endTime: string,     // "HH:mm:ss" format
      startDate: string,   // optional, "YYYY-MM-DD" format
      endDate: string,     // optional, "YYYY-MM-DD" format
      [columnName]: {      // dates for each column
        startDate: string,
        endDate: string
      }
    }
  ],
  columns: [
    {
      uuid: string,
      name: string,
      dateSelection: "from-route" | "user-defined" | "relative",
      relativeDate: string,       // if dateSelection is "relative"
      descriptor: string,
      startDate: string,          // "YYYY-MM-DD"
      endDate: string,            // "YYYY-MM-DD"
      dataColumns: [
        {
          key: "speed" | "speed-pc" | "traveltime" | "traveltime-pc" | "delay" | "delay-pc",
          header: string,
          base: string
        }
      ],
      dataSource: "travel_time_all_vehicles" | "travel_time_freight_trucks" | "travel_time_passenger_vehicles",
      isBase: boolean,
      overrides: {
        aadt: number | null,
        threshold: number | null,
        speed: number | null
      }
    }
  ],
  useBaseAsReference: boolean  // use first column as reference for percent change
}

A route carries its TMC list and a daily time window, and one date range per column, keyed by the column's name. A column names its data source, its date selection and its data columns. Keys ending in -pc are percent changes against the base column; useBaseAsReference selects which of the two values is the denominator. overrides replaces the AADT, the delay threshold speed or the speed used in the delay calculation for that column.

Response

{
  id: string,     // same UUID as request
  data: [
    {
      uuid: string,           // route UUID
      [columnName]: {
        speed: number | null,
        "speed-pc": number | null,
        traveltime: number | null,
        "traveltime-pc": number | null,
        delay: number | null,
        "delay-pc": number | null
      }
    }
  ]
}

One entry per route, keyed by the route's uuid; under it one object per column, holding only the data columns that column asked for. A value is null where the window had no data.

Data columns

The key values a column may request, with the header the tool used.

KeyHeaderDescription
speedSpeedAverage speed in mph
speed-pcSpeed Percent ChangePercent change from reference
traveltimeTravel TimeTotal travel time
traveltime-pcTravel Time Percent ChangePercent change from reference
delayHours of DelayTotal hours of delay
delay-pcHours of Delay Percent ChangePercent change from reference

Data sources

The dataSource values, one per vehicle stream of the NPMRDS travel times table.

ValueDescription

Four scenarios

The reference's own examples, verbatim, with ${API_HOST} standing for https://graph.availabs.org. The TMC codes and values are the reference's illustrations, not live figures.

Single route with speed data

Speed for one route in the morning peak of one quarter.

  -H "Content-Type: application/json" \
  -d '{
    "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "routes": [
      {
        "uuid": "route-uuid-001",
        "rid": 12345,
        "name": "I-87 Northbound - Albany to Saratoga",
        "tmcs": ["120+04567", "120+04568", "120+04569"],
        "startTime": "06:00:00",
        "endTime": "09:00:00",
        "Base": {
          "startDate": "2024-01-01",
          "endDate": "2024-03-31"
        }
      }
    ],
    "columns": [
      {
        "uuid": "col-uuid-001",
        "name": "Base",
        "dateSelection": "from-route",
        "startDate": "2024-01-01",
        "endDate": "2024-03-31",
        "dataColumns": [
          { "key": "speed", "header": "Speed", "base": "speed" }

Sign-in

The reference says of the two pages that "Both routes require authentication". The endpoint is another matter: its handler reads no token, and the server continues without one, so a request such as the examples above, which carry no Authorization header, is answered. If you send a token, send it as the Authorization header, as for the Data Manager API.

The legacy pages

Two page routes call the endpoint, both behind sign-in.

PathDescription
/batchreportsnewMain batch reports page
/batchreportsnew/report/:batchreportIdLoad a saved batch report

The tool those pages replaced took its routes from an uploaded CSV. The 2024 page for it documents the format: no header row; four columns in order, a unique alphanumeric id, a start date and an end date as MM/DD/YYYY hh:mm:ss, and the TMCs of the route joined with the pipe character. A correctly formatted row, from that page:

080966_100554011_DELAY REDUCTION_1,08/24/2018 00:00:00,08/24/2018 23:59:00,120+05065|120+05065

Neither page is in the NPMRDS side navigation. Compare routes across periods describes the successor and what it does today.

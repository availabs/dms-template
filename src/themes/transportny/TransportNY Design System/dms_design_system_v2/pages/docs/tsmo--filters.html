Use the filter bar.

Every TSMO dashboard carries Year and Region. Incidents adds Category, Work Zones adds Type. How to set them, what a blank control means, and what each page leaves out by design.

how-to applies to · TSMO (www/tsmo) last reviewed · 2026-09-05 owner · —

Before you start

Open any of the four dashboards. The filter bar sits under the page title. No account is needed. The address carries your selection, so a copied link reproduces the view.

Steps

  1. Select the value box of Year, the box showing the year. The list opens from the value box, not from the label.You see the years that have data.
  2. Pick a year.The pick replaces the previous year and the list closes. Every panel recomputes. One year at a time: the panels are single-year reads.
  3. Select the value box of Region and pick a region. Regions are listed 1 to 11 in numeric order.The list closes and a ✕ appears beside the region. The headline card titles name the region.
  4. To return to statewide, select the ✕ on Region.The region leaves the address and the page recomputes statewide.
  5. Read the statewide label. The Reliability bar reads no region selected = statewide; its trend title reads statewide unless a region is selected. Congestion's headline titles read the region, or statewide.
  6. On Incidents set Category; on Work Zones set Type. Both behave like Region.
basisA blank Region is statewide: every row in the dataset, including segments that belong to no region. It is deliberately not the sum of the 11 regions. Write "statewide" when you quote it.

What each dashboard leaves out by design

  • Incidents excludes Construction, Maintenance and Emergency Operations, which belong to Work Zones. Since 2026-07-28 the two do not overlap.
  • Work Zones holds only those three categories.
  • Incident Search searches the whole feed, construction included.
  • Reliability has no system or vehicle-class filter. LOTTR is all-vehicle and TTTR is truck by federal definition; the two systems are separate cards.
  • Every dashboard filters by region only. There is no county or MPO filter. Counties are in Corridor View and Incident Search.

Limits and gotchas

  • The list opens from the value box. Selecting the label does nothing.
  • Year is single-select on every dashboard. Region is single-select on Congestion since July 2026 and still accepts several regions on Reliability, Incidents and Work Zones. Incident Search keeps multi-select on every facet because it is a query tool.
  • A blank Region or Category means all of it.
  • The reliability trend shows every year regardless of Year: the measure is annual.
  • Partial years are offered, and show partial totals.
  • The region does not follow you into Corridor View, which is county-keyed. Pick the county there.

Troubleshooting

I cannot see where to select a region

Every control has had a visible border since 2026-07-20. Select the value box beside the Region label. If you see no box at all, reload the page.

I picked a region but a title still says statewide

The numbers always followed the region; until 2026-07-20 some titles were fixed text. If a title still reads statewide with a region selected, report it with the page and region.

The page went blank after I picked a category

Until 2026-07-28 Category on Incidents offered Construction, which the page excludes, so picking it returned zero rows. The list now holds the seven reactive categories. If a panel is blank, clear Category.

HPMS / RIS attributes.

The roadway attributes the measures read from the network: traffic volume, functional system, NHS membership, facility type, speed limit, urban code and occupancy. Where each comes from, how far it lags the travel times, and what is not confirmed. For analysts who weight, filter or monetise.

data applies to · all products last reviewed · 2026-09-05 owner · —

Overview

Every roadway attribute a measure uses lives on the TMC network, not on the travel-time table. Two inventories stand behind them. The Highway Performance Monitoring System (HPMS) is FHWA's national roadway inventory, to which every state reports; its attributes accompany the federal travel-time data. The Roadway Inventory System (RIS) is NYSDOT's own inventory, keyed to the state's linear referencing system. The platform reaches RIS through the OpenStreetMap conflation described on The TMC network and its vintages.

The 2024 report tool exposed RIS attributes directly: AADT variants, posted speed, directional design-hour volume (DDHV), adjusted capacity, volume-to-capacity ratio, K and D factors. The current Macro View does not expose them; the Attributes measure, not yet computed, is their intended home. See Measures that used to be here.

Coverage and vintage

The attributes are re-attached with each network vintage, so their vintage is the network's. The 2024 documentation stated the lag plainly: "NPMRDS data includes traffic volume AADT data from FHWA, but the AADT data lags two years behind the NPMRDS data. So 2020 NPMRDS data is accompanied by 2018 AADT data." Analysts were told to caveat, crosswalk to the matching year, or apply growth factors. The lag is why a fixed panel's directional AADT fell 14.9 % between 2021 and 2022 while the road did not change; AADT and its vintage carries the table.

Two RIS extracts sit in the Data Manager, both archived: a legacy production extract and a 2025 extract with the route, functional class, NHS, jurisdiction, urban area and MPO fields. The legacy tracker recorded "Add 2025 RIS data to the Source" on 2025-08-11 and marked it resolved with a pointer to a newer source. The vintage of the roadway attributes on the 2025 and 2026 maps is not stated in the source metadata. Until confirmed, the AADT vintage on the current map is unstated.

basisAttribute values are per segment and per network vintage, statewide. Name the map year when you quote one.

Schema

The attribute columns on the current network, with the measure that reads each. The full network schema is on TMC network.

FieldTypeSample valueDescription
aadtinteger—Annual average daily traffic, both directions, all vehicles. Read by TED, PHED, the excessive-delay series and cost. Origin: the FHWA traffic-volume data delivered with the network, per the 2024 documentation. The enhanced network's description adds that speed limits, region and MPO boundaries are joined from spatial datasets when the shapefile is built.
aadt_singlinteger—Single-unit truck AADT, FHWA classes 4 to 7 (bus-heavy in New York). Read by the class-weighted value of time.
aadt_combiinteger—Combination truck AADT, FHWA classes 8 to 13.
aadt_unidir · aadt_singl_unidir · aadt_combi_unidirinteger—The three above assigned to this direction, using directionality calculated from the probe data for PHED.
f_systeminteger1FHWA functional system: 1 Interstate, 2 to 7 down to local; 0 marks the extended set of local and unclassified roads. Splits Interstate from non-Interstate in the federal roll-up.
nhs · nhs_pctinteger—NHS code 1 to 9 and the share of the segment on the NHS. The federal measures keep codes 1 to 9.
faciltypeinteger—Facility type 1 to 6. The federal roll-up keeps 1, 2 and 6. The excessive-delay series normalises AADT by it.
structype · thrulanes · thrulanes_unidirinteger—Structure type and through lanes, both directions and this direction.
urban_codeinteger—Census urban-area id; PHED is reported per urbanized area and the roll-up requires it non-null.
avg_speedlimitnumber—Average posted speed limit, calculated from OpenStreetMap speed limits, not from RIS. Sets the excessive-delay threshold; backfilled for 2018 to 2026, missing for 2017.
avg_vehicle_occupancynumber—Persons per vehicle; converts vehicle-hours to person-hours for PHED. Values follow FHWA's average-vehicle-occupancy factors (April 2018).
truck · strhnt_typ · strhnt_pctinteger · string—Truck network flag and Strategic Highway Network type and share.
route_numb · route_sign · route_qualinteger—Route number, signing and qualifier.

The legacy 2019 to 2023 measures table carried the RIS attributes beside the network's under a ris_ prefix: ris_aadt_current_yr_est, ris_aadt_actual, ris_aadt_single_unit, ris_aadt_combo, ris_posted_speed_limit, ris_ddhv, ris_ddhv_factor, ris_adj_cap, ris_v_c, ris_k_factor, ris_d_factor, ris_section_length, ris_divided. That table is archived and no live page reads it.

How it is produced

  1. The vendor's segment file for a vintage arrives with the travel-time data and carries the HPMS-derived attributes: functional system, NHS, facility type, lanes, urban code, routes and AADT with the two truck classes.
  2. The enhanced network build adds the OpenStreetMap-derived speed limit, the region, MPO and urban-area codes, and the directional AADT split.
  3. RIS attributes, when used, reach a segment through the OpenStreetMap conflation, which maps RIS ids and TMC ids onto the same directional OSM segments.

Uses and limits

The delay family and every dollar figure are linear in AADT; a revision to the inventory moves them without any change in traffic. A segment lacking AADT or a speed limit carries no delay; together with the AADT gate, 61 % of network mileage is absent from the delay family. Functional class from the 2017 vintage comes from a different attribute family and is not strictly comparable to 2018 to 2025. Single-unit truck AADT includes buses, so a bus-heavy urban segment reads as truck-heavy for the value of time. The speed limit is an OpenStreetMap average, not the regulatory posted limit on every segment.

Distribution

  • With the network. The Data Manager's network source page carries the attributes per vintage; the Macro View's GeoPackage download carries them beside the measures. See TMC network · distribution.
  • RIS extracts are archived Data Manager sources, not exposed on a public page.
  • HPMS itself is published by FHWA; the Freight Atlas carries a 2018 New York HPMS layer as a map layer. See Freight Atlas sources.

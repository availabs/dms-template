Measures in development.

Three measures are declared in the Macro View's measure reference but not yet computed: free-flow speed, emissions and attributes. This page says what each will be, what blocks it, and how the tool shows the gap. It assumes you know the Macro View.

How the Macro View shows a measure that is not computed

The Macro View declares ten measures. Seven are computed and appear in the Measure menu: LOTTR, TTTR, TTTR₈₀, TED, PHED, percentile speed and data coverage. Three are declared but not computed. They stay out of the menu, so you cannot select one and get an empty map. They still appear in the page's own measure reference with the state not yet computed, so the gap is visible rather than silent.

An absent measure and a measure of zero are different claims. Nothing on the platform shows a zero for a measure it has not computed. When one of the three is computed, it enters the menu and gets a measure page here. The change is dated in Methodology changes.

Free-flow speed

"How fast the road runs when nothing is in the way. The 85th percentile of off-peak observed speed." It sits in the speed group beside percentile speed.

The quantity already exists inside the pipeline. The delay family's free-flow reference is the 15th-percentile travel time of a segment, which is the 85th-percentile speed, the standard convention. The four threshold variants describe how that reference is anchored. What is missing is publication: the reference is not written out as a measure you can colour the map by. Until it is, read a segment's 85th-percentile speed from percentile speed for the period you need.

Emissions

"What the traffic on this segment puts into the air. A speed-binned emission rate applied to the segment's vehicle-miles travelled." Six pollutants are planned. The controls will be pollutant, fuel type, AADT source and peak period, and the unit is tons per year.

The measure is blocked on confirming the emission-rate table with NYSDOT. An emission rate depends on the vehicle fleet, so the rate curve is fleet-dependent. When the measure is published, the fleet year the rates represent will be published alongside every value. No emission figure exists anywhere on the platform today, so do not derive one from a speed and a volume.

Attributes

"Network metadata itself — functional class, AADT, ownership. Coloured straight from a field joined off the network table; no measure controls." The single control will be the attribute to colour by. The unit varies with the field.

This is the intended home for the Roadway Inventory System (RIS) attributes the 2024 documentation listed, such as posted speed and the AADT variants. Measures that used to be here lists them. The fields are not yet joined into the published dataset the Macro View reads. Until they are, AADT still enters every delay figure as a volume, as TED describes, and HPMS / RIS attributes documents the source.

What this means for your analysis

  • For an uncongested reference speed, use the 85th percentile from percentile speed for the period you need. State the period.
  • For the reference the delay measures actually use, read the anchored window named in the Macro View download package, not a percentile speed.
  • For emissions, there is no platform figure to cite.
  • For network attributes, the download carries AADT and functional class beside every measure value.

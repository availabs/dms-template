About these docs

Every page carries the same header: its type, which product and version it applies to, when it was last reviewed, and who owns it. Pages that describe a release not yet live say so. Measure pages are the single source for definitions. The tools show a summary and link here. Figures are captured from the live tool and name the state that produced them.

Sources for every number are listed on the page that shows it. If a page and the tool disagree, either the tool is wrong or the page is stale. Both are bugs: use Help and feedback.

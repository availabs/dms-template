Build a map in the Map Editor.

Create a saved map, add a layer from a dataset version, colour it, write its legend, and save it so pages can use it. A saved map is a named style over one or more dataset versions; it is not a page. This page assumes the data is already uploaded.

how-to applies to · all products last reviewed · 2026-09-08 owner · — requires an administrator account

Before you start

Sign in and open Map Editor from the data administration navigation. You need an administrator account and View source on the dataset you draw — carried by full access, level 10 in the earlier scheme.

Know which dataset and version you are drawing, and check it has geometry — a tabular dataset cannot be a layer. If the data is not loaded, start at Upload a dataset.

Two panels. The map's own is at the top left: its name, its save controls and the tabs Legend · Layers · Plugins. Select a layer and a second panel opens with Style · Legend · Popup · Filter · Join.

Steps

  1. Select the plus in the map panel.In Create New Map, type a Map Name of four characters or more and select Create. For an existing map, use the folder control and Select Symbology › Open Symbology.
  2. Select the plus beside the tabs.The Add Layer dialog opens on the catalog, with Search datasources.
  3. Select a dataset.Its versions appear by Name, Date uploaded and Last modified.
  4. Select the version, then Add layer.The layer appears on Layers in a default style. A version with no tiles is refused: "This view has no tile layers and can't be added to the map." Point data asks for Circle or Heat Map.
  5. Select the layer on Layers and rename it in Layer Name, which the legend and the page's layer list show.
  6. On Style, set Type: Simple for one colour, Categories for one colour per value, Color Range for a graduated ramp, Interactive for several styles a viewer switches between. The last two then need a column in Color By.The map redraws, the legend fills with one row per class or bin, and the rows below change with the type and the geometry; The style controls is the whole set.
  7. Set the colours in Fill, the bins in Scale, and the line work in Stroke, Size, Casing, Offset and Opacity.Offset matters on road networks: both directions lie on one line, so without it only one colour shows.
  8. On the layer's Legend tab, set Legend Type: to Vertical, Horizontal or None and edit each class label.Those labels are the only words a reader gets for your bins: write "60 % and above", not "0.6-1".
  9. Optional: on Popup set the popover to Hover and add fields with Add Column, each taking a Show Column Name and a Format.
  10. Select the save control and, in Manage Changes, choose Save then Save Changes. To keep the original and copy it, choose Save As, type a New Map Name and select Save and Open; to abandon the edits, Discard then Discard Changes.The dialog first says "No pending changes" or "You have unsaved changes".

What you now have

A saved map in the editor's catalog, with styled layers over specific dataset versions. No page has changed: a page holds its own copy, so the map reaches readers only once a page is edited and published — Add a saved map to a page, whose result is a map like the Freight Atlas map.

A layer's own menu holds zoom-to-fit, duplicate and Remove, and layers draw in the order the list shows. The trash control in the map panel deletes the saved map, after a Delete Symbology confirmation.

Pointing a map at a newer version

A layer is bound to one version of one dataset, so a new version does not appear by itself. Either replace the layer — add one from the new version, copy the style across, Remove the old one, which is the only way when the columns differ — or collect the versions: on Style turn on View Group, name it, and add each with Add Data View, one marked as the one it opens on.

Either way, save the map and then refresh and publish every page that uses it. Renaming is the same: on 2026-07-31 two rail-network maps were renamed to drop a version number, and the page showing them still needed publishing.

Limits and gotchas

  • The map draws from tiles, so a column must be in them to be drawn or shown in a popup: one omitted at upload, or not ticked for Mbtile, is unavailable here.
  • The legend does not write itself: bin labels are raw numbers until you edit them.
  • An Interactive layer holds a copy of the style per variant, so restyle every variant or the style reverts when a viewer switches.
  • Saving the map saves the style, not the data: a restyle never changes a dataset, and vice versa.
  • The editor's map is the author's view; readers get the page's copy, at the page's height and legend position.

Troubleshooting

The layer is there but nothing is coloured

Either Color By names a column that is not in the tiles, or every feature has no value. Check the column on the dataset's Columns table, then Show missing data — with it off, valueless features are not drawn.

Only one direction of a road shows

The two directions lie on top of each other. Set Offset so each draws to its own side, scaled with the line's width.

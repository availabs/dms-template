What's new.

What changed on the platform and in this documentation, newest first, one entry per change with a link to the page that carries the detail. For anyone returning to a page and wondering what moved.

log applies to · all products last reviewed · 2026-09-08 owner · —

Each entry carries one of four labels. Platform: a page, a control or a route changed and no number moved. Data release: new months or a recomputation landed. Map/TMC version: the segment network changed vintage. Docs: documentation was published or rewritten. Changes to a definition or a parameter are the fifth kind, and they are not repeated here: Methodology changes is the record of every change to the numbers themselves, and it also holds the platform and data entries below in full. Changes to the APIs and the download routes are in the API changelog.

2026-09-08 · Docs

This documentation set was written, 95 pages covering getting started, the three products, the measures and datasets behind them, the APIs and the administrator's procedures. The pages are drafts awaiting the owner's review, so they are not yet live on the site. See the documentation home for what is here.

2026-09-02 · Platform

TSMO and the Freight Atlas moved onto the landing page's origin, so one sign-in now carries across the products that share it, while NPMRDS keeps its own address and its own session. No number and no API path changed. See Methodology changes and the API changelog.

2026-09-01 · Platform

The Route Creation page published with validated tags, replacing free-text tags with an agency: and user: vocabulary and seeding a new route with the saver's own tags. See Methodology changes.

2026-08-28 · Docs

Two pages of the earlier documentation were rewritten and published, the Macro View guide and the Measures & Methodology page, and the measure pages in Measures & Data are written from the second of them. See Methodology changes for what the rewrite changed about the numbers.

2026-08-25 · Platform

Two charts were corrected: the TSMO Congestion composition chart's grey legend now names recurrent delay as all delay not attributed to an event, and the Freight Atlas home's mode-share chart now reads the 2024 State Freight Plan's own figures instead of deriving shares live. See Methodology changes.

2026-08-24 · Platform

The TSMO home's reliability card split, giving non-Interstate reliability its own equal-weight card and removing TTTR from the home, where a unitless index had nothing comparable beside it. On the same day the Macro View download route stopped offering JSON and began refusing GeoJSON, leaving CSV and GPKG. See Methodology changes and the API changelog.

2026-08-18 · Platform

On the Macro View map the LOTTR target of 1.50 became a colour boundary, and the TTTR threshold was corrected from 1.50 to the 2.00 Interstate target, which moved the share of segments above it from 74.1 % to 44.7 % with no change to the computation. See Methodology changes.

2026-07-28 · Platform

Incidents and Work Zones stopped overlapping, so events whose NYSDOT sub-category is Construction, Maintenance or Emergency Operations belong to Work Zones and the dashboard counts changed while the underlying store did not. See Incidents dashboard and Work Zones dashboard.

2026-07-27 · Data release

The gap in the excessive-delay series was published: the current run covers 2018 and 2021 to 2025, and 2019 and 2020 are not computed. The same publication carried the refresh-cadence table for every feed. See Excessive-delay series and Coverage and freshness.

2026-07-27 · Platform

The Congestion dashboard's link into a corridor was removed, because Congestion filters by NYSDOT region and Corridor View is county-keyed, so the selection could not carry through. On the same day downloads were generated for the 23 Freight Atlas dataset versions that had none, and the TSMO Data & Methodology page's downloads band was relinked to the series source page and the API guide. See Congestion dashboard and the API changelog.

2026-07-20 · Platform

Every TSMO filter control gained a visible border and panel titles began following the selected region, and in the same month Region became single-select on Congestion while staying multi-select on the other three dashboards. See Using the filter bar.

2026-07-19 · Map/TMC version

The platform's current network moved to the 2026 map of 52,473 segments as the travel-time data ran into 2026, so per-segment figures for 2026 are computed on that map while earlier years keep their own. See TMC network and The TMC network and its vintages.

2026-07-15 · Data release

June 2026 landed in the excessive-delay series, the first forward monthly run after the June restart, attributing 36,574 New York events and extending the event-by-segment table through that month. See Excessive-delay series.

2026-06-22 · Data release

Timestamp completeness was measured on 3.7 million TRANSCOM events and published, showing that all lanes reopened is present on 42.7 % of events and incident verified on 20.1 %, so clearance time exists for about one event in five. See TRANSCOM events.

2026-06-13 · Data release

The Congestion dashboard's data revision on the restarted series published 310.86 million vehicle-hours of excessive delay for CY 2025, statewide, all vehicles, 157.07 million of them non-recurrent. See Congestion dashboard and Excessive delay.

2026-02 · Data release

The CY 2025 MAP-21 dataset was computed on the federal cycle, and it is the frozen federal computation rather than the analytical series. See PM3 and MAP-21 datasets.

2025 · Map/TMC version

The 2025 network holds 52,157 segments, and the day the platform adopted it is not recorded. See TMC network.

2024 · Map/TMC version

The 2024 network holds 52,029 segments, and the day the platform adopted it is not recorded. See TMC network.

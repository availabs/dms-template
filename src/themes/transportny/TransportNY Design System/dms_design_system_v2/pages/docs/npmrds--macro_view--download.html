Download data from the Macro View.

Export one PM3 year of a measure for every segment in a geography, as a CSV or a GeoPackage, with a README that says how to read it. The download builder gives you exactly what the map is drawing. This page assumes you have set a measure, a year and a geography on the Macro View.

Before you start

Open Macro View and set the view you want to export: the measure and its controls, the Year, and a Geography if you want less than the state. No sign-in is needed. The bottom bar names the data behind the map and holds the Download N rows button; the count is the number of segment rows the current filter would export. Decide whether you need geometry. A GeoPackage carries the segment shapes for GIS; a CSV is for spreadsheets and code.

Steps

  1. Select Download N rows in the bottom bar.The Download measure data builder opens over the map.
  2. Under Scope, keep Current filters to export the geography on the map, or pick Statewide, <year> for every segment in the year. Each option shows its row count, and a line under them names the geography or reads no geography filter.
  3. Under Format, pick csv or gpkg.
  4. Under Include, select + geometry to add the segment shapes. The button then reads − geometry and wkb_geometry joins the column list.A CSV with geometry carries the shape as text in that column. A GeoPackage needs geometry to be a map layer.
  5. Read Columns you'll get. The measure the map is drawing is highlighted; the identity columns are listed with it. Select a chip to remove that column.
  6. To add columns, open Add metadata column for identity fields or Add measure column for other measures, variants, coverage, precision or era columns, and select what you need.
  7. Select Build N rows · csv (or · gpkg).The builder closes and the bottom-bar button reads Preparing download… while the file is built. A statewide export can take a while.
  8. When the button reads Download N rows · csv, select it.The browser saves a zip holding the data file and PM3_README.txt.
  9. Open PM3_README.txt first and read its coverage and reference notes before you difference anything.

What the package contains

The data file has one row per segment for the year, and the columns you chose. Column names follow the dataset's own scheme: the measure, the variant, the period and the unit joined by underscores. The LOTTR AM-peak ratio is lottr_amp_lottr; TED against the fixed free-flow reference, all traffic, in vehicle-hours, is ted_freeflow_anchored_all_xdelay_vhrs; the share of AM-peak bins reporting is coverage_all_vehicles_amp_pct_bins_reporting. The identity columns include the TMC code, the year, the county, the region, the MPO and the urban area. Each measure the package can carry has its own page: LOTTR, TTTR, TTTR₈₀, PHED, TED, percentile speed and coverage.

PM3_README.txt is written for the year you exported, so two years' packages read differently. It states:

  • The export. The dataset, the year, the format, the scope, the row filter and the exact column list.
  • The coverage era. Which all-vehicle and truck coverage eras the year falls in, with a warning when the year crosses an era boundary, and a note if no era column was exported. See Coverage eras and comparability.
  • The free-flow reference window. The fixed window the anchored delay threshold is taken from, whether the exported year overlaps it, and the anchor_fallback rows to exclude from any trend.
  • Delay columns. Which variant answers which question, the 20 mph floor and the share of delay it governs, and the AADT vintage warning when the year sits on a revision boundary. See Which measure should I use? and AADT and its vintage.
  • Reliability columns. That nothing is suppressed for being imprecise, how to read the precision columns, and that pmp names a different window for the delay measures than for LOTTR and TTTR.
  • If you compare years. A checklist, and the statement that the file is not for federal submittal.

How to cite a download

Cite the analytical series, never a federal figure, and give enough for someone to rebuild the file: the measure and variant as the column name reads, the PM3 year, the scope, the download date, and the README's coverage era line. A shared Macro View address is live and can change; the export is fixed. Example: "TED, fixed free-flow reference, all traffic, vehicle-hours (ted_freeflow_anchored_all_xdelay_vhrs), PM3 year 2025, Albany County, TransportNY Macro View download of 2026-09-05." For the federal figure use the MAP-21 annual download instead.

Limits and gotchas

  • Two formats only. JSON was removed on 2026-08-24 because the export pipeline cannot write it; GeoJSON is refused as a matter of policy. A Shapefile is accepted by the server but not offered in the builder.
  • The two scopes are the geography on the map and the whole state. There is no "one region, all measures" export; add measure columns to the current filter instead.
  • The dataset behind the map carries no road name. Join the TMC code to the TMC network datasheet's fields for names, lengths and AADT.
  • A delay export without its anchor_fallback and precision columns cannot be screened for trend use; the README says so when they are missing. Add them before you build a series.
  • Values are the analytical series. The README ends with "not for federal submittal". Federal PM3 and what this site publishes explains.
  • The download gives the year on the map. To compare years, export each year and read both READMEs' era lines first.

Troubleshooting

Nothing happened after Build

Reported on 2026-08-24. The cause was found and fixed in the code: the request and the poll for the finished file used different keys, so the file was built but never offered. The fix is pending deployment, together with the server change it needs. Until it is deployed the button can still fail silently. If it does, report it with the year, the scope and the time.

The builder shows a message under the button

The line under Build normally reads "Values are exactly what the map is drawing". When the server refuses a request, an unknown column, an unsupported format or a bad geography filter, its own message replaces that line. Remove the column or change the format and build again.

The row count reads a dash

The count has not loaded yet, or the map has no measure column. Wait for the map to colour, then reopen the builder.

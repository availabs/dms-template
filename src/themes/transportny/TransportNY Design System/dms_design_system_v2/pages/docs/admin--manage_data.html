Manage a dataset.

Curate a dataset that is already uploaded: the description and categories readers search by, the column display names that make it a data dictionary, a new version, the download files, who may see it, and the two kinds of delete. This page assumes a dataset exists and that your account can edit it.

Before you start

Open the dataset from the catalog and read what a reader sees — Download freight data describes the same page from the outside. The tab bar reads Overview · Table · Map, with Admin for administrators. Each task needs its own permission, and a control you cannot use is not shown.

Steps

The curation pass, on Overview. Every edit here is public the moment it saves.

  1. Hover the Description card and select the pencil.Say what the dataset contains, what it measures, and where it came from with its vintage — the provenance readers look for. It saves as you write.
  2. Hover Categories, select its pencil, type a category and press Enter; the cross on a pill removes one, and sub-categories work the same way. The hint reads "Start typing to add new category", then "Press Enter to save or Esc to cancel".Categories place the dataset in the catalog's rail and the product's navigation, so use the ones the product already uses.
  3. In At a glance, select the pencil beside Update interval and say how often the data is replaced; leave it empty only for a one-time load.The rest of that card is fixed, and Updated is the date the record was edited, not the vintage of the data.
  4. Select Edit columns in the Columns header, or Advanced Metadata on the Admin tab. Both open the same metadata page, one row per column.
  5. For each column fill display name and, in the advanced panel, description; name is the stored name and is fixed.Those two are the reader's Column and Description. Until you write them, readers see raw column names.
  6. The advanced panel, opened by the row's ... control, holds Column Type, Required, Index, Primary Key and Sort as. Drag rows to reorder; New field name... adds one and delete removes one.
  7. Read the Columns table on Overview as a reader. Anything still unnamed is work left.

Versions and downloads

A version is one iteration of the same dataset: same columns, new data. Data whose columns changed needs a new dataset.

  1. Select Add Version on the Admin tab.The upload flow opens attached to this dataset; follow Upload a dataset from the file step, matching every column to an existing Database Column Name.
  2. Name the version in its Version field — a year, a release date, the publisher's own version.Newest is first, with a current badge, its row count and its publication date.
  3. On the version's page select Create Download, which opens the Create Data Download dialog.
  4. Tick the formats under File Types and the columns under Columns; Toggle All selects or clears a group, and calculated columns are refused. To split the export, set Split data files to Yes and pick a column.
  5. Select Start download creation.When the job finishes a Download button appears on that version; several formats open a menu. Each is a zip.
  6. To replace them, select Delete Download and build again — the dataset and the version are not affected.

Access and deletion

The Admin tab's Access panel is where a dataset stops being private. Grant View source to read and Download source to add the file, and grant the public group to make it genuinely public. A dataset with no grants is open to any signed-in account, which is not the same as public. Users and permissions is the reference.

Delete removes the dataset and version records; the data tables and files stay and could be recovered. Hard Delete also drops each version's table, removes the files and deletes the load history, so it asks you to type the dataset's name.

cautionDeleting a dataset does not repair the pages that used it: a card or table bound to it stops returning rows. Check what points at it first — see Keeping a page's map in step.

The Tasks list at the foot of the tab logs this dataset's loads and jobs — Task ID, Type, Status, Started, Duration — and a row opens its events. This is the earlier guidance's Events log.

Limits and gotchas

  • Overview edits save as you make them. There is no draft and no undo.
  • Type is fixed at upload; a tabular dataset cannot become a GIS one.
  • Download files are built from the columns you ticked; a column added later is missing until you rebuild them.
  • A column deleted on the metadata page disappears from every table, download and map that names it.

Troubleshooting

The pencil icons are not there

Your account does not carry Update source here, or your session expired. Reload; if they are still missing, ask for the permission or report it.

Start download creation is disabled

One group is empty, or a calculated column is selected. Tick at least one format and one column, and clear anything marked calculated.

A new version has no Download button

Download files belong to a version, so every new version starts without them; build them with Create Download. On 2026-07-27 the 23 Freight Atlas versions that had none were generated in CSV, ESRI Shapefile and GPKG — the shape of a normal backfill.

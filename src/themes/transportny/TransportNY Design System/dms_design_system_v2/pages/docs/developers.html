The two APIs

The platform exposes two programmatic surfaces. Both answer on the data host, https://graph.availabs.org. Neither has an OpenAPI document; these pages are the reference.

APIWhat it isWhereStatus
Data Manager APIA Falcor JSON Graph endpoint. You send a list of paths under the uda root and get back a graph of values. It reads any published dataset by view: its length, its rows, its columns, filtered and grouped.GET https://graph.availabs.org/graph?paths=…&method=getCurrent. The 2025 reference's dama root is the legacy form.
Batch Reports APIOne REST endpoint. You post a list of routes as TMC lists with time windows and column definitions; it returns speed, travel time and hours of delay per route and period.POST https://graph.availabs.org/batchreports/npmrds2/982Retires when Route Comparison is released.

Sign-in is separate from data reads. A token comes from POST https://dmsserver.availabs.org/login and lasts about 6 hours. Public reads need none. See the quick start's first step and Sign in, sessions and accounts.

Where the data comes from

Every dataset the API serves has a datasheet in Measures & Data. Each datasheet's Distribution section names the routes to that data. Read the datasheet before you query: it carries the schema, the coverage eras and the limits that the API does not repeat.

  • NPMRDS travel times · the 5-minute probe table; the Macro View download carries computed measures, not epochs.
  • TMC network · one vintage per year; geometry travels in the Macro View GeoPackage.
  • PM3 and MAP-21 datasets · the analytical series per segment and year; the federal submission file on the MAP-21 pages.
  • TRANSCOM events · the dataset the worked examples query.
  • Excessive-delay series · segment by month; a CSV per year from the TSMO Data & Methodology page.
  • HPMS / RIS attributes · travel with the network, not on their own.
  • Routes data · saved routes; no bulk download.
  • Freight Atlas sources · the Data & Downloads catalog, per-version exports in four formats.

What is not offered

  • No OpenAPI or Swagger document. The Data Manager API is a path grammar, not a set of REST resources. These pages are its description.
  • No published rate limit. None is published. The data server's own code sets none; what a proxy in front of it enforces is not documented here.
  • No API key apart from the sign-in token. The TSMO Data & Methodology page's "key on sign-in" is the token the quick start mints.
  • No bulk export of the raw travel-time table. The routes to that data are the Macro View package and per-view reads through the API. See What is not downloadable.
  • No write access to platform data. Dataset rows are never editable through the API. Source and view descriptions can be edited with a token that carries edit authority.
  • No client library other than the python client, which is installed from its repository, not a package index.

Recipes.

A recipe is a deliverable a planner already recognises, a bottleneck ranking, a Congestion Management Process, a before-and-after study, worked end to end on this platform: the question, the tools, the steps, how to read the result, and what the output looks like. Three recipes so far. Written for MPO and county planners and NYSDOT program staff.

What is here

Each recipe follows one shape: The question in a planner's words, What you need (tools, sign-in, data), Steps, Reading the result, Variations, and Sample output. The how-to pages say what each control does; a recipe says which controls to use, in which order, to produce one document.

Start here

Pick the recipe by the document you owe. A ranking of where congestion is worst in a region is the composite score. A federally required congestion process for an MPO is the Congestion Management Process. A project evaluation is the before/after study. If you have never used the tools, do the ten-minute start first: every recipe assumes you can open the Macro View and build a report.

Two rules run through all three. Read Data coverage before trusting a pattern, because thin data inflates reliability ratios and deflates delay. And keep the two measure families apart: recipes use the analytical series from the Macro View and Reports; a figure for a federal document comes only from the MAP-21 PM3 pages.

Common tasks

  • Rank a county's segments by several measures at once, with weights you choose.
  • Choose the measure for each CMP step: TED per mile to rank segments, TED total to report them.
  • Compare a corridor before and after a project with two windows on one route.
  • Turn hours of delay into a dollar figure, and say which value of time you used.
  • Cite a download so a reader can rebuild it.
  • Propose a recipe. If your agency produces a document from these tools that is not here, describe it through Help and feedback: the question, the tools you used, and what the finished output looked like. Recipes that more than one agency needs are added to this hub.

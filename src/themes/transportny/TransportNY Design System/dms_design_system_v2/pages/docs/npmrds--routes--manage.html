Find, edit, tag and share routes.

Saved routes are found through the Add Routes dialog of a report, edited on the Route Creation page, grouped by tags, and shared by address. Folders no longer exist; tags replace them. Written for anyone who has saved a route or needs one a colleague saved.

Before you start

There is no routes page. Routes are listed where they are used: the Add Routes dialog in a report's Routes rail, and the picker of the draft Route Comparison tool. To open that dialog you need a report of your own in edit mode, so sign in and either create one or open one you own. Editing a saved route itself happens on Route Creation, by address.

Two things are both called a route. The saved route is the segment list with its name and tags. The route row in a report is a reference to it plus a date window and a colour. Renaming or re-dating the row does not change the saved route.

Steps

  1. Open a report you own, select Edit, then Add Route in the Routes rail.The Add Routes dialog opens on All Routes with a search box, a Browse by tag row and a ranked list.
  2. Type part of a name in Search routes by name….The list narrows as you type. Each row shows the name, the segment count, an ownership badge (Mine, Curated or Auto-generated) and its tag chips.
  3. Or browse. Select County, Region or Agency, then a value.The breadcrumb reads All Routes / County / Dutchess, for example, and the list holds routes carrying that tag. Other tags searches free-text tags such as a project number.
  4. Narrow with the chips beside narrow by: Mine for routes you created, Curated to hide generated ones, Auto-generated to see only those.The count line reads "N routes". clear resets the chips.
  5. If the route is a single segment, select Show short segments too. Single-segment routes are hidden in browse views because they are most of the catalogue.
  6. Change the order with the sort control: Best match, Recently updated or Name (A–Z).
  7. Tick one or more routes and select Add N Routes.Each becomes a row in the rail. A route already on the report is flagged Already on report in targeted views and can be added again, for a second date window.
  8. Edit the row in the rail: the pencil renames it for this report only; From and To set its dates; the colour dot opens the identity colour palette. These save at once, outside the page's draft.
  9. To change the saved route, open /route_creation?route_id= and its number, edit segments, name, description or tags, and select Update route. Every report that uses it inherits the new name.
  10. To share a route, copy that same address. Anyone can open it. Tell them not to save, because saving from that address overwrites your route.

How tags work

A tag is a short label on a route. Four kinds exist. user: followed by your id marks the routes you own and shows as the chip You. agency: followed by a code marks an agency or group, for example NYSDOT, CDTC or SMTC; you can only add agency tags for groups you belong to. county: and region: place the route; the dialog offers the 62 counties and the 11 regions by name. Anything else is free text and is found through Other tags. A new route is offered your own tag and your group tags as + chips.

Tags also decide what you see by default. Signed in, a picker shows routes you created, routes tagged with your user or agency tags, and the generated routes. Show everyone's widens it to the whole catalogue. For agency users the restricted view is the default; the wider view is the default only for the platform's own staff accounts.

Limits and gotchas

  • Folders are gone. The earlier tool's folder tree, including My Stuff and the regional default folders, was not carried over. Tags carry the grouping. Two folder complaints from May 2026 are moot for this reason.
  • A route's name is shared. Renaming in the rail changes this report's label only; renaming on Route Creation changes it everywhere.
  • Most routes were generated by a service account, not drawn by a person; they carry the Auto-generated badge. The catalogue also holds duplicates, so the same route can appear twice.
  • Ownership is read from the signed-in account on your side only. It is a convenience, not a permission.
  • No page lists or downloads all routes. The Routes data datasheet says what can be read another way.

Troubleshooting

I cannot find a route I saved

Select Mine. If it is one segment long, select Show short segments too. If a colleague saved it, browse by their agency or turn on Show everyone's.

I cannot add an agency tag

The dialog refuses tags for groups you are not in and reads You're not in X — ask an admin to add you to that group first. Ask through Help and feedback.

A colleague opened my link and my route changed

The address carries the route id, so their save overwrote it. Rebuild the segments and save again. To hand over a copy instead, ask them to clear the id from the address before saving.

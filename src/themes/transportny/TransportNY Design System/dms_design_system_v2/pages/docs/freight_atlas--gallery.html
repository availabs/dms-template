Freight Atlas · how-to

Open one of the plan's maps.

The Maps Gallery is the 2024 State Freight Plan's map figures rebuilt as presets of the Freight Atlas map. 22 of the plan's 33 maps are tiles today, in seven categories. How a tile opens the map, why an eighth category is hidden, why 11 figures are not there yet, and how to go from a plan map to your own. No account is needed.

how-to applies to · Freight Atlas (www/freightatlas) last reviewed · 2026-09-07 owner · —

Before you start

Open Maps Gallery in the Freight Atlas side navigation. The header says what the page is: "Every map from the 2024 State Freight Plan, rebuilt as a live Freight Atlas view — each tile opens the single map engine preloaded with that figure's layers." Below it, a status line counts the figures that are live and the ones still to come. Have the plan to hand if you want to compare a tile with its printed figure; The report library says where the documents are.

Steps

  1. Choose a category. Seven titles run down the page, each with its map count, for example Maritime, Air & Pipelines · 3 maps.Under each title, one tile per figure.
  2. Read a tile. It carries the plan's figure number and page, the figure's title, a sentence of the plan's own context, and a footer with the number of layers and open in Freight Atlas →.The figure number and page let you find the same map in the plan.
  3. Select open in Freight Atlas →.The map opens with that figure's layers on, REDC regions behind them where the plan drew a regional background. The Map layers panel counts them and the Legend shows a block per layer. The address ends in ?layers= and the ids of those layers.
  4. Read the map with Use the map: hover for a popup, use the legend's info button for the dataset, change a layer's Show view where it has one.
  5. Make it yours. Tick more layers under Add layers, remove any you do not want, then copy the address.The gallery's last card says the same: "Don't see your view? Build it." A copied address is your own preset.
  6. Return with Maps Gallery in the side navigation.The map does not keep your layers when you leave, so keep the address if you want them back.

Why a category can be hidden

The gallery has eight categories in its dataset but shows seven. A category with no live figure is not rendered, and the counts beside each title count live figures only. The eighth, 2050 Outlook, holds the plan's four forecast maps, none of which the map can draw yet. It appears by itself when its first figure goes live. Nothing on the site says "8 themes"; instructions that do are out of date.

Why some figures are not there yet

Eleven of the plan's 33 maps have no tile. They stay in the gallery's dataset as the work queue, and each is missing one of two things.

Three tiles reproduce their figure only in part. Freight-Reliant Industry Hotspots (2021) draws a business-density heat map, not the plan's per-industry hotspots. Border Crossings, Inbound Volumes shows the crossings but not their volumes, which need Bureau of Transportation Statistics border data. New York's Pipeline System lacks the plan's crude-oil rail terminals, an Energy Information Administration layer not in the plan's data delivery.

Limits and gotchas

  • A tile's address carries layers only. Undesignated Truck Parking — New York City opens at the map's default position; zoom to the city yourself.
  • A tile's layer count counts the layers it turns on, background included.
  • The plan's figures were drawn from the plan's data at the plan's date. A tile draws the live layer, which can carry a later vintage than the printed figure. Check the layer's vintage in the Layer reference before comparing numbers.
  • The gallery page has a draft and a published version; readers see the published one.

Troubleshooting

I only see 7 themes but expected 8

Seven is correct today. The eighth category has no live map and is hidden until it does. See Why a category can be hidden.

A tile opened with a road network I did not ask for

Until 2026-08-24 the Freight Core Highway Network was on by default in the stored map, so every tile drew it under the figure's layers. Every layer now starts off and the address alone decides what draws. If a tile still shows it, reload and report it with the address.

The map does not match the printed figure

Three tiles are partial by design, listed above. For any other tile, compare the legend labels with the figure's legend and the layer's vintage with the figure's data year. A different colour ramp is a styling choice; a missing class is worth reporting.

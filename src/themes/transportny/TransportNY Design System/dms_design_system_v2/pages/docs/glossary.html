Glossary.

Every term this documentation uses, defined in one sentence, with the product and screen where you meet it and a link to the page that owns it. For anyone reading a dashboard label, a column name or a measure for the first time.

glossary applies to · all products last reviewed · 2026-09-08 owner · —

One entry per term. The meaning comes first, then Pathway, the product and screen the term belongs to, then the page that defines it in full. Acronyms are filed by their letters, and an entry that starts with "the" is filed under the word after it. Where a term names a control, the page it links to prints the label as the screen prints it.

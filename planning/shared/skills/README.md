# Shared skills

How-to guides for cross-project dms-template work — the `shared` project's counterpart to
[`planning/mitigateny/skills/`](../../mitigateny/skills/README.md) and
[`planning/transportny/skills/`](../../transportny/skills/README.md).

> **Why these are here and not in `src/dms/skills/`.** That directory is the `@availabs/dms`
> submodule and is the right home for guides about *library capability*. These guides are about
> client work and deliverables, so filing them there would force a submodule commit for no library
> benefit. `planning/planning-rules.md` allows project material that isn't a task to live directly
> in the project folder; `shared` is the project for cross-project work.

## The skills

| Skill | Use when |
|---|---|
| [`drafting-a-final-report/`](./drafting-a-final-report/README.md) | Writing a project final report for an agency client — locating the contractually required structure, building a source corpus from contracts/minutes/presentations/the live platform, keeping a traceable fact ledger, and shipping a designed HTML document that converts cleanly to Word. Carries the NYSDOT PPDAF report as a worked example with its verified findings. |

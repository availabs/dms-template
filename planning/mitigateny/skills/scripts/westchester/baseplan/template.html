Westchester needed no hazard-taxonomy decision — a first. Suffolk required a hybrid mapping across split and combined profiles; Schenectady needed three renames and two dropped hazards. Here all sixteen doc profiles land on the sixteen platform hazard pages unchanged.

Why the alignment holds

The document’s heading tree is the platform’s component order.

Read down a hazard page and the correspondence is positional, not just nominal. Every heading the consultant wrote either names an Annotation slot outright or sits exactly where the platform puts a data component — which is the signal to transcribe nothing there.

Doc headingComponentWhat it is on the page

Coastal Hazards, page 2448355. Teal rows are the fill targets; the rest the platform renders itself from geoid-filtered sources. The same shape repeats on all sixteen hazard pages.

The county chapters behave the same way: the document uses a literal Local Context heading wherever the platform has an Annotation titled “Local Context”. Built Environment is the cleanest case — the doc’s eight Local Context sections and the page’s eight Local Context Annotations appear in the same order, one to one.

Drift register

Nine items where the document and the template have moved apart. Three block the workbook load.

D8 Three pattern-level fields did not survive duplication blocker
  • filters still carry geoid 36105 — that is Sullivan. Westchester is 36119. Every geoid-filtered data component on the site is currently pointed at the wrong county. county_template holds the same placeholder, so this is a required post-duplication step rather than template drift.
  • additionalSectionAttributes is absent. It defines the status select — including shmp_sourced_content, the value this load writes. Without it the status won’t render in the admin UI. Copy from pattern 1300890.
  • authPermissions is absent. Almost certainly why 9 of the 58 page rows read back no-access. Copy from pattern 1300890.
D1 Six county-specific sections have no slot anywhere owner decision
  • Executive Summary, plan-wide, 3,983 ch — no plan-wide Annotation exists; the Home page’s six are nav cards. Nearest homes: The Plan Executive Summary 2449721, or a new Home component.
  • Letter from the Director, 2,150 ch — county-specific, no slot at all.
  • Formal Adoption by Westchester County and Participating Jurisdictions, 609 ch — closest slot 2463655 is already claimed by the doc’s own Adoption section. Merge, or add a component.
  • Background, 4,298 ch — half of it belongs. Paragraphs 590–593 and 598 are county-specific (45 jurisdictions, 430.8 sq mi, the three coterminous town-villages, what changed since the last plan); 594 and 599–602 plus Table 1 are 44 CFR boilerplate the shared cards already carry.
  • Risk Assessment Terms, 888 ch — a generic glossary. Recommend skipping, or appending to 2465617.
  • Capabilities Assessment overview, 1,317 ch — the four-capability framing. The page’s first Annotation is order 5 (Planning and Regulatory); order 1 is a data Card. Recommend prepending, or adding a page-overview Annotation to the template.
D3 Climate Change has one Annotation for two large doc sections owner decision

Local Context (3,382 ch) and Shared Socioeconomic Pathways (9,999 ch, 14 paragraphs) both have to land in 2449756, the page’s only Annotation. Recommend merging under an SSP sub-heading, or adding a second Annotation. Do not write to component 2449734 — that is the shared statewide Climate Impacts Matrix, 21,347 characters of hazard-by-hazard climate text used by every county.

D4 Five doc sections narrate a data table with no Annotation beside it owner decision

Each is folded into the nearest slot, which is where the Medium and Low confidence rows in the crosswalk come from: Demographic Statistics (2,432 ch) into the People and Communities Local Context; Future Population Projections (1,318) into Population Change, whose guidance explicitly asks for projections; Open Space Parcel Statistics (979) into County Open Space Plan — the one Low-confidence call, and a reasonable candidate to drop; Local Funding Capabilities (675) into Funding Sources Local Context; and Goals and Objectives (499), a definitional lead-in, prepended to County Goals and Objectives.

Present in county_template too, so this is a template defect to fix and propagate rather than a duplication error. Does not block this pass — the document carries no prose for any of the three.

D9 Two stale references carried over from the template template defect
  • Page 2448340 (“Response”, under Strategies) has parent = 1300884 — a county_template page id, not a page in this pattern. Its parent pointer needs re-pointing at the Westchester subtree.
  • Slot 2450153 sits directly under the NFIP page’s “Floodplain Administrators” card, but its guidance still reads “Provide information on your latest Flood Insurance Rate Map.” And 2449901 (Built Environment, Buildings) carries guidance copy-pasted from the Critical Buildings slot. D5 Lightning has no County Assessment heading single exception

Its county-level assessment prose (3,292 ch) sits under Local Risk Assessment instead — which on the platform is a plain header, not an Annotation. Target is the County Assessment slot 2451746. This is the only hazard subsection in the entire document that doesn’t match a slot title.

D6 The doc’s per-hazard Overview has no slot of its own convention

It corresponds to platform order 5, a shared data Card. Content exists for only three hazards — Drought (1,498 ch), Wildfire (350), Ice Storm (219) — and is folded into Local Hazard Summary alongside General Vulnerability, whose 44 CFR tags (B2-a, B2-b) match that slot exactly.

What did not drift

Otherwise the copy is structurally identical to county_template: the same 256 Annotation slots, the same slot titles, the same per-page component counts, across all 49 shared pages. The template has one extra page the copy lacks — jurisdictional_annexes/select_jurisdiction, which holds no Annotation slots.

What happens next

  1. Owner decisions on D1, D3, D4 and D7 — the six no-target sections, the Climate Change merge, the five table-narration folds, and whether the six empty slots go back to IEM.
  2. Clear D8 before the workbook load. Set filters to geoid 36119; copy additionalSectionAttributes and authPermissions from pattern 1300890. The internally-sourced tables, cards and graphs won’t render against Westchester until the geoid is right.

  4. Back up, dry-run, apply to draft_sections across the ~174 target slots at status: shmp_sourced_content. Nothing gets published — that stays a human decision.
  5. Re-run the slot inventory and reconcile filled counts against the crosswalk.
  6. Then the jurisdictional annexes — 45 documents into the Jurisdictions dataset, the path already proven on Nassau, Suffolk, Schenectady and Delaware.
  7. File D2 and D9 as county_template findings, for propagation to every duplicate pattern.
